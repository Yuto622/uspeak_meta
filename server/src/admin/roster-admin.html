U-Speak 管理 — 名簿（ログインできるアカウント名）

…

ON にすると、下の名簿にあるアカウント名の子しかログインできません（クラスは問いません）。OFF の間は、クラスコードを知っていれば誰でも入れます。
TEACHER_KEY を持つ先生は名簿に関係なく入れます。制限は サーバー側 で判定し、名簿がブラウザーに渡ることはありません。

この切り替えはいま環境変数 ACCESS_MODE で固定されています。変えるには fly secrets unset ACCESS_MODE を実行してください（そのあとはこのスイッチが効きます）。
TEACHER_KEY が設定されていません。制限を ON にすると先生も入れなくなります。
名簿は Google スプレッドシート（ROSTER_SHEET_ID）から読んでいます。名前の追加・削除はそのシートで行ってください。ここでは見るだけです。
⬇ CSV で保存
#アカウント名（ロビーで入力する名前）
0 人 ● 保存していない変更があります 大文字小文字・空白・全角半角は区別しません。

CSV の形：1行に1つのアカウント名。1行目が name や アカウント名 なら見出しとして飛ばします。class,name の形でも name 列だけ読みます。Google スプレッドシートや Excel の「CSV でダウンロード」がそのまま読めます。
貼りつけ：スプレッドシートの名前の列を選んでコピーし、「貼りつけ」に貼ると表に入ります。
保存を押すまでサーバーには書かれません。保存するとその場で効きます（授業中でも）。

貼りつけ

1行に1つ、アカウント名を貼ってください（スプレッドシートの列をコピーしたものでも大丈夫です）。
