# U-Speak STEM Web — 筋がいいか（リサーチのみ・まだ作らない）

2026-10-01 時点。検索は約45回。多くの一次サイト（edtechzine・矢野経済・qureo.jp・group.gmo・
treebell-jp.com など）はこの環境から開けなかったので、数字の一部は検索結果の要約・二次報道から
取っている。**【未検証】【要一次確認】の印があるものは、商談・資料に使う前に一次資料で確かめること。**
為替は 1ドル＝150円で仮置き。

## 0. 結論

| 形 | 判定 |
|---|---|
| **独立した新商品「U-Speak STEM Web」**（QUREO と同じ、塾向けのプログラミング／理科ライセンス） | **No-Go** |
| **既存の U-Speak Web に足す「English × STEM（CLIL）ユニット」**（英語で理科・プログラミングを学ぶ） | **条件付きで Go**（8週間の小さな検証が先） |

理由は3つ。

1. **国内の主戦場は寡占されている。** 塾向けのプログラミング教材は QUREO が約3,300教室を押さえている。
2. **理科の仮想実験は、民間の需要も公教育での位置づけも弱い。**
   - 文科省は「ICT は観察・実験の代替ではなく補助」という立場。
   - PhET（シミュレーション集）が無料で使える。
3. **Roblox を「集客の入口」にする設計は、規約上むずかしい。** 13歳未満は外部リンクを共有できないので、Roblox から有料の Web 版へ直接案内できない。

**ただし「英語×STEM を塾向けライセンスで体系的に出している大手」は見つからなかった。** 空いているのはここだけ。

**読みかた。**

- 国内の子どもプログラミング市場は約270億円で、天井は低い。
- いちばん伸びているのは受験向け（共通テスト「情報」）と、大手教材への集約。
- U-Speak の顧客である子ども英会話教室の市場は縮んでいる。そのぶん教室には「付加価値をつけて単価を上げたい」動機があり、アドオンには追い風になる。

## 2. 政策の追い風

- **必修化が進んだ。** 小学校プログラミング（2020年）→ 中学技術（2021年）→ 高校「情報Ⅰ」（2022年）→ 共通テスト「情報Ⅰ」（2025年、受験者 約28万人）。
- **次期学習指導要領**：中教審の部会が 2026-09-25 に審議まとめを了承した [18][19][20]。
  - 小学3年生以上の「総合的な探究の時間」に情報の領域が入る。
  - 中学に新しい教科「情報・技術科」ができる。
  - 小学校の情報教育は **2028年度から先行実施**。
  - **英語の授業での AI 活用が、初めて明記された。**
- **NEXT GIGA**（学校の端末の入れ替え）：入れ替える台数は2025年度に474万台、2026年度に455万台 [21][22]。
- **理科**：ICT は観察・実験の代替ではない、というのが文科省の立場 [25]。

→ 「情報」と「英語×AI」には強い追い風がある。**理科の仮想実験は、公教育の方針とは真正面からはかみ合わない。**

## 4. Roblox を入口にすること

**追い風**

- 小学生の「いちばん遊んでいるゲーム」で 12.7%、2位（2026年6月の調査、n=367）[47]。
- 日本の1日あたりの利用者は、2022年第4四半期から2024年第4四半期で +120% [48]。
- Roblox は 2025年7月に学習向けの Learning Hub を始めた [49]。

**制約**

- **チャットに顔での年齢推定が必須になった**（2026年1月から、世界一律）。日本の13歳未満は保護者の同意が必要 [50][51]。
- **13歳未満は外部リンクを共有できない** [52]。Roblox の中から Web 版へ直接案内することはできない。
- **米国で、州の司法長官による提訴が少なくとも11州**。ロシアは2025年12月に Roblox を遮断した [53][54]。
- 国内でも「被害が多い」という報道があり、保護者の安全面の見かたは悪くなっている [55]。

→ **「教室で先生が使わせる体験の場」としては有効。集客の入口として頼るのは危ない。**
U-Speak Roblox を今のまま入口にするのはよいが、STEM 版の売上をそこに依存させないこと。

## 5. ツリーベルの既存クラスへの横展開は筋がいいか

**筋がいい点**

- 「子どもにさせたい習い事」は6年連続で、1位が英語、2位がプログラミング [56]。
- 契約・研修・アカウントをそのまま使い回せるので、新しく客をとるコスト（CAC）はほぼ 0。
- 日本の小学校の CLIL（教科の中身と英語を一緒に学ぶ方法）の実践研究で、意欲や発話が増えたという報告がある [57][58]。

**筋が悪い点**

- **ツリーベルはすでにマイクラ教育版でプログラミング教室を運営している** [33]。新しいプログラミング教材は、既存講座と食い合うか、置き換えを迫る提案になる。
- 民間プログラミング教室のいちばんの悩みは講師不足 [59]。英語講師に「プログラミングそのもの」を教えさせるのは重い。

| 講師研修 | 中 | 英語講師だけで回せる設計が必須 |
| 食い合い | 中 | ツリーベルの既存のマイクラ講座と重なる |

**「リスクがなければやる」という条件には、いまの形では当てはまらない。** 大きいリスクが4つある。

## 7. やるならこの形：English × STEM（CLIL）ユニット

**目的は「プログラミングを教える」ではなく「英語で考え、英語で指示する」。**

- プログラミングは、命令ブロックがぜんぶ英語。
  - 例：`move forward` / `turn left` / `repeat 3 times`
- 理科は、観察と予想を英語で言う。
  - 例：`I think it will sink because…`
- 英検の語彙・表現とつなげる。成果は**英語の成果**として、毎月の保護者レポートに出す。
- **英語講師がそのまま回せる**ようにする。QUREO も Scratch もやっていないところ。
- いまの仕組み（島・サーバーの判定・先生コンソール・保護者レポート）がそのまま使える。
  島を1つ（「ラボ島」）足すのが、いちばん小さい形。

**価格の仮説**：新しい商品にはしない。

- 780円の AI プランに含めるか、＋200〜300円/人/月 のアドオンにする。
- 参考：Tynker 約170円、CodeCombat 約625円、Labster 約750円。

### 8週間の検証

1. **ツリーベルの2〜3クラス（児童30〜50名）＋比べるためのクラス1つ。**
2. **CLIL ユニットは4〜6本だけ作る。**
   - プログラミング：ブロック命令を2本。
   - 理科：うく・しずむ／じしゃく／しょくぶつ の3本。
   - Roblox 側は体験の入口だけにする。
3. **測るもの**
   - 週ごとのアクティブ率
   - ユニットを最後までやった割合
   - 対象の語彙の事前・事後テスト（比べるクラスとの差）
   - 講師の準備時間
   - 保護者アンケート（上乗せ料金を払う気があるか）
   - ツリーベルが有償で採用する気があるか

**Go の基準（ぜんぶ満たしたら）**

- 週ごとのアクティブ率が 70% 以上
- 語彙の伸びが、比べるクラスをはっきり上回る
- 講師の準備が1回10分以内、研修が30分以内
- 保護者の40%以上が、月500円以上の上乗せを受け入れる
- ツリーベルが＋200円以上で有償採用に合意し、ほかの教室1つからも基本合意をもらう

**No-Go の基準**：上の基準を満たさないとき、または理科ユニット1本を作るのに2週間以上かかるとき。
→ Web 版英語の拡販に集中しなおす。
