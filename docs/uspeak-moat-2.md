# 競合と引き離すための施策 — リサーチと、入れたもの

社内メモ。`docs/uspeak-retention.md`（継続の仕組み）の続き。今回は「**競合がまねしにくい形で、
教室が手放しにくくなるもの**」を調べてから、8つ入れた。コードの頭の注から、ここを参照している。

## 1. 調べて分かったこと（出典は末尾）

| 事実 | 数字 | 設計への意味 |
|---|---|---|
| 子ども英語教室の**退会理由の1位は「塾が始まるから」** | 不満ではなく時間の奪い合い。次いで日程・受験・引越し | レッスンを良くしても止まらない。**塾と併走できる形**が要る → おうちの日・今日の5分 |
| **高学年で保護者の問いが変わる** | 4〜6歳は「楽しそう」で満足 → 高学年で「これは何につながるの？」 | 中学英語・英検への**接続を学校の言葉で**言う → 中学の目安 |
| **月次継続率の業界平均は93〜97%** | 97%超が優良、90%割れが不調 | 個人教室は自分の数字を知らない → **教室のようす**（経営の画面） |
| **システム/スクール管理費の相場が既にある** | 保護者が月1,000〜3,000円を払い慣れている | 値付けの器がもうある（新しい名目を作らなくてよい） |
| **英検の準会場は、2〜5級の志願者10人以上で開ける** | 検定料が本会場より安くなる（最大4割）。二次を準会場でやるには2〜3級で60人以上 | 教室の運営の真ん中。ここに入れば抜けない → **準会場の見込み** |
| **Roblox 英語に資本が入ってきた** | イオンファンタジー「ゲームカレッジLv.99」が Roblox 英語コース（特別コース月額10,780円・入会金11,000円・週1回60分のオンライン） | **コンテンツ勝負は負け筋**。相手は B2C で、教室の運営には入れない |
| **AI 発音採点・CEFR-J 判定はもうコモディティ** | ELST・スピークバディ・スタディポケット（音素単位・5軸） | 自前で作っても差にならない（通話と同じ構図）→ やらない |
| **学習データの標準化は未整備** | 学習eポータル／MEXCBT は公立校向けで、LRS の規格も揃っていない | 民間教室が相手のうちは、対応しても見合わない → やらない |

### 競合の地図

- **コンテンツ**（島・ゲーム・Roblox）… 資本で殴られる。真似もされる。
- **AI 採点** … コモディティ。後発で差がつかない。
- **教室の運営に入り込む記録層** … **ここだけ空いている。** Comiru（4,000教室以上）は
  「誰が来たか」（連絡・請求・入退室）を持つが学習の中身を持たない。学習アプリは
  「何ができるか」を持つが在籍を持たない。**両方を1つの画面で持っているのは U-Speak だけ。**

## 2. 入れたもの

| # | 施策 | どこ | 何が手放しにくくなるか |
|---|---|---|---|
| ① | **教室のようす**（利用継続率・12か月の折れ線・業界平均の帯・今月まだの子・はじめて3か月未満・声かけの結果・英検の準会場） | `server/src/game/classview.js`、`/class/:classCode?t=…` | オーナーが毎月開く**経営の画面**になる |
| ② | **おうちの日・今日の5分** | `months.js` の `home`、`quick5.js`、`client/dist/quick5.js` | 退会理由1位（塾）への反論の材料が、記録として残る |
| ③ | **英検の目安と準会場の見込み** | `eiken-ready.js` | 教室の英検運営そのものが、ここを通る |
| ④ | **中学の目安**（英検5級＝中学1年生くらい…） | `eiken-ready.js` の `SCHOOL`、`months.js` の `eg` | 「何につながるの？」に学校の言葉で答えられる |
| ⑤ | **先生のメモ**（保護者に見せる／見せない） | `notes.js`、先生コンソール | **先生が書いたものは、どこにも移せない**（いちばん強い乗り換えコスト） |
| ⑥ | **声かけの記録と、その後** | `notes.js` の `call`、教室のようす | 「声をかけた子のうち何人が戻ったか」が教室の中に溜まる |
| ⑦ | **面談メモ**（話すことの自動生成） | `report.js` の `talkingPoints`、`?view=meet` | 教室の面談の運用に入る |
| ⑧ | **学習の記録証** | `report.js` の `certHtml`、`?format=cert` | 辞める理由を「卒業」に変える紙 |

## 3. 守ったこと（言いすぎない）

- **利用継続率は「来たか」で数える。** 月謝の在籍はこのサービスには分からない。だから名前は
  「利用継続率」で、定義を画面に書いてある。人数が少ない月は「1人で大きく動きます」と添える。
- **英検は合格の予想ではない。** 島の練習問題の直近20問の正解率。**やさしい判定の○は数えない。**
  5級・4級は「よむ・きく」、3級は「よむ・きく・かく」で決め（一次の中身に合わせる）、
  3級の「はなす」は二次として別に出す。画面の言葉は「練習で目安に届いています」。
- **声かけは因果を言わない。** 比べる相手がいないので、「声をかけたから戻った」とは書かない。
  出すのは「声をかけた N回のうち M回は、14日以内にその子が戻ってきた」という起きたことだけ。
- **先生のメモは既定で保護者に出さない。** 「保護者のレポートにのせる」を付けたものだけ。
  声かけは保護者には一切出ない。**CSV にはメモを全部出す**（教室が書いたものは教室のもの）。
- **記録証は公的な資格ではない。** 期間・来た日・答えた問題と、英検は「練習で到達」とだけ書く。
- **おうちの日は端末の申告ではない。** 部屋に先生（講師キーで入った人）がいたかを、サーバーが見て決める。

## 4. やらないと決めたこと

| やらない | 理由 |
|---|---|
| AI 発音採点の自前開発 | ELST・スピークバディ・スタディポケットが先行。コモディティ |
| 通話の強化 | `docs/uspeak-moat.tex` のとおり。使うほど赤字に近づく |
| 島やゲームを増やして勝とうとする | 資本で負ける土俵。維持だけ |
| 学習eポータル／MEXCBT 対応 | 公立校向けで、データの標準も未整備。顧客が民間教室のうちは見合わない |

## 5. 値付けへの反映（奥田さんへの相談用）

- **ベース**（記録・レポート・教室のようす・英検の準会場・先生のメモ）＝固定費。
  保護者が既に払っている「システム管理費」（月1,000〜3,000円）の枠に収まる形を探る。
- **上位／オプション**（AI 英会話・音声）＝従量。1日40往復・音声120分の上限つきで別建て。
