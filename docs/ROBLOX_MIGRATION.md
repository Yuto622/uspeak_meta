# Roblox → Web 移管：機能インベントリと仕分け

U-Speak Roblox（PlaceId 139338411931177）の全ダンプを読んだ結果です。
**スクリプト 398 本・全文**、**インスタンス 4,675 件**（装飾を除いた分）を解析しました。

まだコードは1行も書いていません。この文書の仕分けと島割りに承認をもらってから着手します。

| # | 決定 | 状態 |

### ③a AIの人格 ── 実装した内容

Roblox の `AiChat.server.lua` v3 から、人格ルールと出口ガードの両方を移しました。

- **人格ルールを最優先**に置きました。プロンプトの先頭が `IMPORTANT CHARACTER RULES` で始まり、
  その後に場面の説明が続きます。名前を聞かれたら必ず `My name is Upee! (ぼくは ウーピーだよ！)`。
  AI・言語モデル・プログラムだと名乗ることを禁止。ChatGPT / GPT / OpenAI / Claude / Gemini の
  名前を出すことを禁止。
- **おつかい島の店員は「ウーピーが演じている役」という扱い**にしました。プロンプトは
  「いまは Sunny Bakery の Oliver を演じている。会話中は役を保つが、本当は誰かと聞かれたら
  ウーピーとして答えて続ける」と指示します。
  → パン屋には店員がいて、でも中身のAIはどこでもウーピー1人、という形です。
  **もし「店員も全員ウーピー（フクロウ）にする」意図だった場合は言ってください。**
  `missions.json` の `character` と島の住人モデルを差し替えるだけなので、変更自体は軽いです。
- **出口ガード**も入れました。プロンプトを守らなかった場合の最後の砦です。
  Roblox 版は単語を置換していましたが、それを移植したところ
  `I am Upee, a Upee made by Upee.` という文が出たため、**方式を変えました**。
  モデル名や「言語モデル」「人工知能」に触れた返答は、部分置換ではなく
  **返答まるごと**を `My name is Upee! Let's keep going in English.` に差し替えます。
  ヒント（日本語）が触れた場合は表示しません。ふつうの返答には一切手を触れません。
  日本語の「あい」を誤爆しないよう、`AI` は大文字のみを見ます。

### ① 武器 ── 決定：移管しない

杖に一本化します。夜のおばけ（E2）を実装するときは、叩く手段を杖だけにします。
Web 版にはすでに杖（`magic.js` / `wandModel` / `magic-data.js`）があるので、新規の武器実装は不要です。
`ServerStorage.Weapons` の 62 本、`Famas Spawner`、`Pistol`、`Handgun`、`WeaponServer`、
`WeaponMenu`、`WeaponShopUI` は移管対象から外します。

### 魚は突き合わせではなく選択でした

両方のデータを突き合わせた結果、**そもそも別物**でした。統合の余地はありません。

| | Roblox | Web（現行） |
|---|---|---|
| 中身 | 実在の魚 100 種（ヒトデ・サメ・ジンベエザメ・ウーピーフィッシュ…） | 架空の魚 100 種（コモレビメダカ…） |
| 英語 | **なし**（魚は魚） | **1匹＝英単語1つ**（`word` / `meaning` / `grade`） |
| 絵 | `rbxassetid://` の実イラスト（U-Speak制作） | 手続き生成の3Dモデル（形・色・模様をパラメータで） |
| 価格 | レア度別 3〜600🪙 | 18〜（`price`） |

**推奨は「Web の魚を残し、Roblox の経済だけ移す」です。** 理由は2つあります。
Web の魚は1匹が英単語1つなので、釣ること自体が学習になっています（これを捨てると
釣りがただの収集になります）。そして Roblox のイラストは Roblox にホストされた
`rbxassetid://` なので、Web で使うには 100 枚を再アップロードする必要があります。

移すのは中身ではなく**仕組み**です：レア度別価格（3〜600）、図鑑の初ゲット +10🪙、
買取屋、魚でわざを覚える。

## 0b. 判断の材料（記録）

### ① 武器がなぜ「取り込みゴミ」ではないのか

`ServerScriptService.WeaponServer` はレベル制限つきで武器を配っており、`WeaponMenu` /
`WeaponShopUI` という UI もあります。つまり武器は**意図的に組み込まれた機能**です。
用途は `NightGhostManager` にあるとおり「⚔️ぶきで叩くと キラキラ弾けて Uコインを落とす」——
夜のおばけを叩いてコインを稼ぐ手段です。

ただし中身は shotgun / tommy gun / Famas / Handgun / Flare Gun でした。小学生向けの英語学習
サービスに実銃を持ち込むかは経営判断なので U-Speak Lab に確認し、**杖に一本化する**決定を
もらいました（上記①）。同じフォルダにあった `Magical wand` の役割を、Web 版の既存の杖が担います。

### ② 取り込みテンプレートが 175 本あります

398 本のうち 175 本は `City_Template`（街の建物キット・85本）、`ServerStorage.Weapons`（62本）、
`EnemyZombie`、`Famas Spawner`、`退避_テンプレ残骸` など、外部から取り込んだものでした。
`EnemyZombie` は `NightGhostManager` のコメントで「既存の ZombieManager を無効化すること」と
名指しで置き換え対象になっており、**すでに死んでいるコード**です。これらは移管対象外と判断しました。

### ③ ダンプに含まれていた資格情報

自動で伏せ字になったもの（**3 件とも `ServerScriptService` / `ServerStorage` にあり、プレイヤーからは
読めません。置き場所は正しいです**）:

| 場所 | 内容 |
|---|---|
| `ServerScriptService.AccessGate` | `TOKEN`（40文字） |
| `ServerScriptService._BAK_AccessGate_preautorecover` | 同上（旧版のバックアップ） |
| `ServerStorage.Secrets` | `OPENAI_API_KEY`（164文字） |

伏せ字にならなかったが、**扱いに注意が要る URL が 2 件**あります（変数名に key/token が入って
いなかったため素通りしました）:

- `ServerScriptService.Script` の GAS URL（クラスコード → PlaceId 照会）
- `ServerScriptService.ParentReportQRServer` の保護者レポート URL
  `https://uspeak-reports.pages.dev/treebell-c_RPqFBihvw/qr/index.json`

後者はパスの `treebell-c_RPqFBihvw` が推測不能な文字列であることだけで守られている構造です。
**この2つの URL は、いま私との会話履歴に平文で載っています。** 保護者の学習記録に繋がる導線なので、
心配なら発行し直してください（Roblox 側とレポート側の両方の差し替えが要ります）。

## 0c. 土台（実装済み・2026-09-10）

順番の「1. 土台」を実装しました。`server/src/game/progression.js` が XP と レベルの唯一の持ち主です。

### レベル曲線は Roblox のまま

```
次のレベルまで = 20 + レベル × 10      Lv1→2 は 30 / Lv2→3 は 40 / Lv10→11 は 120
```

Roblox の `XPCore` と同じ式です。**累計XPは保存せず、レベルと現XPから毎回逆算します。**
これも Roblox（`SheetSync` v6.2）と同じ考え方で、だからシートとゲームの数字が食い違いません。

### 保存項目の対応表

| Roblox（DataStore 属性） | Web（`players` シート列） | 備考 |
|---|---|---|
| `XP` | `xp` | レベル内のXP |
| `Level` | `level` | |
| `XPToNext` | *保存しない* | `20+Lv×10` で導出 |
| （なし） | `total_xp` | 分析用に毎回計算して書き出し |
| `ChatCount` | `chats` | |
| `Coins` | `coins` | 既存 |
| `LevelUpTick` | *移さない* | Roblox 側の演出用フラグ |
| `TutorialDone` | *未* | チュートリアルを作るときに |
| `PhraseDex` | *未* | A9 で |
| `BlocksData` / `USpeakOwnedBlocks` | *未* | D1 建築で |
| `LoginStreak` / `LastLoginDay` | *未* | B4 デイリーログインで |
| `CharDex` / `CharMoves`（別DataStore） | *未* | A5 / C4 で |
| `OwnedOutfits` / `WornOutfits` | *未* | F2 きせかえで |
| FishDex（別DataStore） | *未* | C2 魚図鑑で |

列は**末尾に足すだけ**にしてあります。既存のスプレッドシートを開いたとき、ヘッダーが
短ければ自動で継ぎ足し、順序が食い違っていれば触らずに警告だけ出します。

### 報酬レート（`REWARDS`・1か所）

Roblox の調整をそのまま持ってきました。**しゃべる行為がいちばん高い**という順序が要点です。

| 行為 | XP | コイン | 由来 |
|---|---|---|---|
| おつかいのお題を1つ達成（英語で話す） | 15 | 0 | Roblox `GymXP` の「音声系は最高単価」 |
| 単語クイズ 正解 | 10 | 10 | Roblox `WordHouseQuiz` v4.7 |
| 島の会話クエスト 正解 | 10 | 0 | |
| 釣りの単語 正解 | 10 | 0 | コインは魚そのものが報酬 |
| キャラ図鑑 初登録 | 5 | 5 | Roblox `CharWorldService` v1.2 |
| 定型フレーズを送る | **1** | 0 | **下記の理由で Roblox の 5 から下げています** |

**1か所だけ Roblox と変えました。** Roblox はチャット1発話 = 5XP でしたが、あれは
子どもが**打った**文章です。Web版のチャットは定型フレーズを**1タップ**なので、
同じ5XPだと連打で稼げてしまいます。1にしてあります。教室で物足りなければ
`REWARDS.phrase.xp` の1か所を変えるだけです。

### 決めたこと

- **XP を配る入口は `awardXp()` ただ1つ。** クイズもおつかいもフレーズも全部そこを通ります。
  保護者レポートの数字を問われたときに読む場所が1か所で済みます
- **レベルは公開情報**にしました（`Player.level`）。先生の名簿に Lv 列が出ます
- **オンラインならサーバーの値が勝ちます。** コインと同じ扱いです。
  オフライン1人用モードでは従来どおりローカル計算のままです
- 壊れた保存値からレベルを錬成できないよう、読み込み時に「レベル内XPはそのレベルの
  必要量未満」に丸めます

### 持ち物上限（C7）は見送りました

Roblox は Tool を10個までに制限して入れ替えUIを出しますが、**Web版に Tool という概念が
ありません**。所持品は「アイテムID → 個数」のマップで、スロットではありません。
枠の概念がないところに枠だけ持ち込んでも意味がないので、建築（D1）で
実際に持ち物が増えるときに、Web の形に合った上限を設計します。

## 0d. ことばの学校島（実装済み・2026-09-10）

順番の「2」。Roblox の `WordHouseQuiz_ServerOnly_ProximityPrompt` v4.7（2,347行）の移管です。

### 小屋に入る＝難易度を選ぶ

島に3つの小屋（やさしい／ふつう／むずかしい）が建っています。**メニューで難易度を選ぶのでは
なく、入りたい小屋まで歩いて入ります。** 1セット10問。おつかい島と同じで、サーバーは
その小屋の前に立っていないと出題も採点もしません。途中で小屋を出ても中断にはならず、
戻れば続きから答えられます。

### 問題は 1,501 問、ブラウザには渡していません

Roblox の問題バンクをそのまま移しました。

| | 問題数 |
|---|---|
| やさしい | 508 |
| ふつう | 489 |
| むずかしい | 504 |
| **合計** | **1,501** |

**この機能だけ、判定データをクライアントに置いていません。** レッスンや魚の正解キーは
`client/dist` にあります（画面に問題を描くのがクライアントなので必然です）。単語クイズは
サーバーが問題文と4択だけを送り、正解は子どもが選んだ**後**に届きます。
だから読み取れる正解がそもそも存在しません。Roblox も同じ作りでした。

代償として**小屋はオンライン専用**です。おつかいと同じで、これは仕様として書いています。

### 移す前に見つかったデータ不良を直しました

Lua のテーブルは同じキーを2回書くと後勝ちで、前の値が消えます。バンクにそれが8箇所あり、
**うち3問は「正解の選択肢が消えて、別の選択肢が正解ということになっていた」**——
つまり**正しく答えた子が不正解にされていました**。

| 問題 | 何が起きていたか |
|---|---|
| `____ many books do you have?` | `C="How"` が `C="Where"` に上書きされ、正解が "Where" に。**How を選んだ子が不正解** |
| `____ is the first month of the year.` | A と D がどちらも "January"。**D を選んだ子が不正解** |
| `The sun ____ in the east.` | A と C がどちらも "rises"。**C を選んだ子が不正解** |
| 他5問 | 選択肢が3つしか出ていなかった（D が空欄） |

8問すべて直し、重複していた28問を1つにまとめました。**Roblox 側にも同じ不良が残っています。**
上の3問は今も間違って採点しているので、直すなら該当行を直接修正してください。

読み込み時に「選択肢が4つあるか」「同じ選択肢が2つないか」「正解が実在するか」を検証し、
1つでも欠ければ**起動しません**。同じ不良が二度と入りません。

### 報酬

Roblox と同じです。正解 = **+10 XP +10🪙**、10問全問正解で **+10🪙ボーナス**。
出題ごとに選択肢をシャッフルします（Roblox がそうしたのは、正解が A に偏っていたからです）。

### 島を作る仕組みを共通化しました

おつかい島と学校島は「同じ島に違う建物が建っているだけ」だったので、地形・桟橋・当たり判定・
光の柱・ミニマップを `client/dist/island-kit.js` に出しました。各島が書くのは建物と住人だけです。

あわせて **`ACTIVITY_HUBS`** を作りました。学習用の島は宝箱と U-Speak park の入口を持たない、
というルールをデータ側に持たせたものです。おつかい島を足したとき宝箱が3つ勝手に増えて
全地域の秘宝がずれる事故があり、学校島でも同じことが起きかけました。次の島では起きません。

### ことばのジム（A3・実装済み）

同じ島に、小屋とは別の建物として建てました。Roblox の `ListenSpeakGym` v5.1 の移管です。
1セット5問、正解 = **+15 XP +5🪙**（音声系が最高単価という Roblox の順序どおり）、
結果は★3段階。単語は Roblox の **110語**（どうぶつ30／たべもの25／がっこう22／
しぜん12／のりもの8／せいかつ13）をそのまま持ってきました。

| モード | 中身 |
|---|---|
| 👂 きく | ウーピーが英語で言う → 絵4枚から選ぶ |
| 🎤 はなす | 絵と単語を見て → 英語で言う（マイク or 文字入力） |

**Roblox 版のサーバー権威の穴を塞ぎました。** `GymXP.server.lua` は、クライアントが
「正解した」と `UspeakGymXP` を撃つと**中身を確認せずに 15XP と 5コインを払っていました**。
1.2秒のクールダウンだけが歯止めで、誰でもタイマーで稼げる状態です。Web 版では
**サーバーが単語を持ち、サーバーが判定します。** はなすモードでクライアントが送るのは
「マイクが何と聞き取ったか」だけで、正解かどうかは送りません。

**発音の判定は Roblox と同じ考え方**（レーベンシュタイン距離）ですが、線の引き方を明示しました。
`rabbit` に対する `rabit` は**マイクの誤りなので正解**、`cat` に対する `cut` は**別の単語なので不正解**
（ただし「おしい！」と出ます）。1文字の誤りを許すのは4文字ごとに1つ、最大2つまで。
つまり3文字の単語は完全一致が必要です。発音練習なので、ここは緩めませんでした。

**きくモードだけは、正解が導出できます。** ブラウザが英単語を読み上げる必要があるので、
読む単語をクライアントに送らざるを得ないためです（島のレッスンや魚と同じ制約）。
判定はサーバーがしますが、「知られない」ことは保証できません。はなすモードにはこの穴はありません。

## 0e. えいごアリーナ島（CPU戦・実装済み・2026-09-10）

順番の「3」。Roblox の `BattleService` v1.7.1 の移管です。

### ダメージは英語で買う

これが移してよかった設計です。**わざは4つあり、強い3つは英語のもんだいに答えないと出ません。**

| わざ | 効果 | もんだい | 制限時間 |
|---|---|---|---|
| ぽよんアタック | 10 ダメージ | なし | — |
| えいごビーム | 18 ダメージ | あり | 10秒 |
| スーパーワード | 28 ダメージ | あり | 8秒 |
| にこにこヒール | 15 かいふく | あり | 10秒 |

答えれば勝てて、安全なボタンだけ押す子はじわじわ負けます。**まちがえるとわざが不発**になり、
ダメージは0です（相手のターンは来ます）。

CPU は Roblox と同じ3段階：らくらく（命中40%・HP60）／ふつう（60%・90）／つよい（80%・120）。
自分の HP は Roblox の式そのままで `60 + レベル×8`（ペットではなく子ども自身のレベル。
ペットは順番の5なので、来たら差し替えます）。

問題は Roblox の `BattleQuizBank` から **249問**（元は254問、英単語が重複していた5問を1つに統合）。
**バンクはサーバーにあり、ブラウザには来ません。** 送るのは問題文と3択だけで、正解は
子どもが選んだ後に届きます。

### 1日のコイン上限

Roblox の `DAILY_CAP = 150` を移しました。勝ち15🪙／負け10🪙で、
**上限に達した分は「残っているぶんだけ」払います**（最後の1戦が丸ごと0になるより、
半端でも受け取れるほうが納得できるので）。上限に当たってもバトル自体は続けられます。

### おさかな道場（順番の4・一部）

アリーナ島に5つめの建物として建てました。`FeedMoveService` の移管です。

**おさかなを1ぴき たべさせると、その子の わざを おぼえます。** おぼえたわざは
アリーナで**5つめのボタン**になり、他の強いわざと同じく英語のもんだいつきです。
魚は消え、まえのわざは忘れます（Roblox と同じで、とくいわざは常に1つ）。

**魚→わざの対応は作り直しました。** Roblox は日本語の魚名の部分一致（`ゴールデン` なら
きんのかがやき、`サメ` ならかみつき）でしたが、Web版の魚は英単語を持つ架空の魚
（コモレビメダカ / apple）なので、その名前は1つも一致しません。**残すべきルールは
「レアな魚ほど強いわざ」**だったので、それを軸にしました。レア度が強さを決め、
釣り場（池・川・海）が名前を変えます。わざ11種の名前・ダメージ・制限時間は Roblox のままです。

| レア度 | 池 | 川 | 海 |
|---|---|---|---|
| ふつう | おさかなパワー 22 | パンチパンチ 24 | はさみアタック 24 |
| すこしレア | トゲトゲガード 24 | すみはき 26 | ジェットふんしゃ 26 |
| レア | でんきショック 28 | こうそくアタック 30 | こうそくアタック 30 |
| とてもレア | かみつき 34 | かみつき 34 | りゅうのなみ 38 |

## 0f. ペット島（実装済み・2026-09-10）

順番の「5」。Roblox の `PetService` の移管です。

**世話が「歩くこと」になっています。** たまごの巣で たまごを買い、ごはん処で ごはんをあげ、
ふれあい広場で なでる。3つの建物が別々の場所にあるので、ペットの世話は島を歩くことです。

| | Roblox | Web |
|---|---|---|
| たまご | 300🪙・6種からランダム | 同じ |
| ごはん | 20🪙・おなか +40・XP +5 | 同じ（ごはん処で） |
| なでる | 無料・60秒に1回・ごきげん +10・XP +2 | 同じ（ふれあい広場で） |
| レベル | `floor(xp/25)+1` | 同じ |
| 減衰 | おなか・ごきげんが1日で100減る | 同じ |

**移してよかったのは減衰の作りです。** Roblox は「最後に見た時刻」からの経過で計算していて、
ティックを回していません。だから**オフラインの時間もそのまま数えられます** — 1日ぶり
に会いに来た子のペットは、ちゃんとおなかを空かせています。そのまま移しました。

**おなかがいっぱいのときの「ごはん」は拒否**で、課金しません（Roblox と同じ）。
壊れた保存値は丸ごと捨てます（存在しない種類のペットは復元しない）。
コインの支払いは `spend` というサーバー専用の操作にしたので、
クライアントからは呼べません（`catch` / `award` と同じ扱い）。

## 0g. 日課（実装済み・2026-09-10）

順番の「6」。**島ではありません** — Roblox の `DailyLogin` / `WeeklyRank` /
`SeasonManager` を、世界そのものの層として `ClassRoom` に足しました。

| | Roblox | Web |
|---|---|---|
| 日の境目 | 日本時間 12:00 | 同じ |
| ログインボーナス | 7日サイクル 100→150→200→250→300→350→400🪙 | 同じ |
| 連続日数 | 前日ならつながる／1日空くと1に戻る | 同じ |
| ランキング | スクールコード別・今週の XP | クラスコード別・今週の XP・上位10名 |
| シーズン | JSTの月で 春3-5／夏6-8／秋9-11／冬12-2 | 同じ |

**境目が「深夜0時」ではなく「おひる12時」なのが肝です。** 授業の途中で日付が変わりません。
朝の8時と昼前の11時59分は同じ日で、12時ちょうどから次の日になります（`test/daily.test.mjs`
がこの境目を固定した時刻で検査しています）。

**ボーナスは `welcome` を組み立てる前に財布へ入れます。** 順番が逆だと、参加した直後の
コイン表示が一瞬だけ古く、すぐ書き換わります。子どもには「増えた」ではなく「バグった」
ように見えるので、入金 → `welcome` → お知らせ（`login:bonus`）の順に固定しました。

**受け取りの記録はサーバーが持ちます。** 再読み込みしても、その日はもう払われません
（`test/e2e/browser-daily.mjs` がブラウザで実際にリロードして確認しています）。
クライアントから「今日のぶんをください」と言う口はありません。

**週の集計は自分で切り替わります。** 週が変わったかどうかは保存された週番号と
今の週番号を比べるだけで、リセットのバッチはありません。先週の合計が今週の合計として
復元されることもありません（`sanitizeWeek` が週番号ごと捨てます）。

ランキングは**今つないでいる子だけではなく、そのクラスの記録ぜんぶ**から作ります
（`store.listClass()`）。休んだ子の名前が消えるランキングは、ランキングではないからです。

画面は `client/dist/daily.js`。参加した瞬間のスタンプカードと、右側の「♛ 週間ランキング」
ボタンだけで、順位も金額も一つも計算していません。

## 0h. 世界の演出（実装済み・2026-09-10）

順番の「7」。E1 時間帯・E2 夜のおばけ・E6 環境音。これも島ではなく世界の層です。

### E1 時間帯

| | Roblox | Web |
|---|---|---|
| 長さ | 昼300秒／夕120／夜240／朝45 | 同じ（1周 705秒） |
| 決め方 | サーバーの `TimeManager` | **時計の関数**（`client/dist/world-clock.js`） |

**空は「設定」ではなく「時刻」になりました。** ブラウザとサーバーが同じ1ファイルを読み、
同じ瞬間からは必ず同じ空を出します。**同期のための通信はゼロです** — 状態がないので、
ずれようがありません。参加したときにサーバーの時刻を1回だけ聞いて、あとは自分で回します。

そのため、**画面右の「時間」ボタンは切り替えではなく時計表示**になりました
（`☾ よる 3:16` のように、次の時間帯まで何分何秒か）。押すと「夜はみんないっしょに
やってきます」と教えます。ひとりだけ昼にできてしまうと、隣の席の子と別の世界になり、
「おばけがいる／いない」が食い違うからです。

`WORLD_TIME_OFFSET_MS` で世界の時計をずらせます。テストが11分待たずに夜へ行くためのもので、
授業のデモで「いまから夜」を見せるのにも使えます。ずらした時刻がそのままクライアントにも
伝わるので、**ずらしても全員が同じ空**です。

### E2 夜のおばけ

| | Roblox | Web |
|---|---|---|
| 数 | ランダム湧き | 12体・場所は固定（データ共有） |
| 🎃 | 4体に1体 | 同じ（3体） |
| 触られたら | 空腹が少し減るだけ | **なにも起きない** |
| 叩くと | コインを落とす | 3🪙＋英単語。1晩60🪙まで |
| 朝 | 消える | 同じ |

**こわくない設計です。** 血も、やられも、追いかけっこもありません。触っても何も起きず、
**近づいて杖をふる**ことでだけ捕まります（ユーザー判断で「叩く手段は杖に一本化」）。
ポップするときは、ふわっと大きくなって消えます。

**おばけは英単語を1つずつ持っています。** つかまえると読み上げ＋単語帳に入り、コインが付きます。
「夜のワールドを歩き回ると単語が増える」という形にしました。

サーバーが持っているもの：いま誰が出ているか、その子がそのおばけの**隣に立っているか**、
今夜いくら払ったか。クライアントは「これをふった」と言うだけです。
**25秒で戻ってくる**ので、25人のクラスが12体を取り合いにはなりません。

### E6 環境音

Roblox の音源アセットは持ち出せないので、**ブラウザに音を作らせています**
（`client/dist/ambience.js`）。昼は風と鳥、夜は風が弱まりコオロギ。
音量は小さく固定です — 25台のiPadで鳴るので、**子どもの発話より大きくなってはいけません**。
最初のタップまでは鳴りません（iPad Safari の仕様であり、行儀でもあります）。

## 0i. のりもの島（実装済み・2026-09-10）

順番の「8」。E3 乗り物の移管です。

| | Roblox | Web |
|---|---|---|
| 解放条件 | Level + Coins（ティア別） | 同じ（4台・★1〜★4） |
| 看板 | 条件を満たすと金色に変わる | 同じ（ゲートのカードが金色に） |
| 買う場所 | 乗り物ごとのゲート | 同じ（島の4か所に分かれている） |
| 運転 | VehicleSeat の物理・ネットワークオーナー移譲 | **移していません**（別物なので） |
| かわりに | — | **6つの ことばのゲートを 順番に走るコース** |

**物理は移していません。** Roblox の乗り物は本物の車体で、運転する子にネットワーク
オーナーを渡す作りでした。Web で同じものを作るのは別のゲームを作るのに等しいので、
ここでは**乗り物＝速さと見た目**です。

**そのかわりに「コース」を足しました。** 島のまわりに6つのアーチが立っていて、それぞれに
英語の方向のことば（go / right / straight / left / slow / goal）が大きく書いてあります。
順番にくぐるとラップ完了。**乗り物に乗っていないと走れません**し、順番が違うと
「つぎは ○○ だよ」と言われるだけで進みません。走ることが、ことばを読むことになります。

**買うのは歩いた先です。** キックボードはキックボード置き場でしか買えません
（別のゲートからは「べつの ゲートに あります」）。サーバーが見るのは
**レベル・コイン・その子がそのゲートの前に立っているか**の3つです。

**キックボードの値段は 100🪙 = ログインボーナス1日目**にしてあります。
はじめて来た日に、ちょうど1台買えます。

ラップは 15XP + 10🪙、**1日10ラップまで**（アリーナ・おばけと同じ、記録に残る日次上限）。
ガレージ・いま乗っているもの・自己ベストは記録に残ります。

## 0j. まちづくり島（実装済み・2026-09-10）

順番の「9」。D1 建築 + D2 マイルーム。移管リストで**最も重い**と自分で書いた機能です。

**Roblox の設計を、考え方ごと持ってきました。** `HousingService` は**街に置くのは入口だけ、
部屋は入る瞬間に生成**という作りで、これが効きます — 部屋は誰かが中にいる間しか
存在しないので、**600人の学校でも25人のクラスと同じコスト**です。

| | Roblox | Web |
|---|---|---|
| 部屋 | インスタンス方式（入口だけ街に） | 同じ |
| ブロック | `USpeakOwnedBlocks` = **種類を1回買う** | 同じ（10種・それぞれ英単語つき） |
| 設置 | グリッド3・所有チェック | グリッド1・所有チェック・**下から積む** |
| 引っ越し | Level + Coins で広い部屋へ | 同じ（8×8 → 12×12 → 16×16） |
| 共有建築エリア（D3） | 別プレイスへテレポート | **移していません**（下記） |

**保存が軽いのが肝です。** 自分の懸念（「同期と永続化のコストが最も高い」）に対する答えが
Roblox 側にありました。**買うのは種類、保存するのはマスの一覧**なので、1人ぶんは
「持っている種類（最大10）」と「置いたマス」だけです。

サーバーが1マスずつ見ているもの: グリッドの中か・天井より下か・買った種類か・
すでに何か置かれていないか・上限内か。そして**何も浮きません** — ブロックは床か
別のブロックの上にしか置けず、積み上がった下のブロックは抜けません。
壊れた保存値は**そのマスだけ**捨てます（広い部屋の記録を狭い部屋で読むと、
はみ出したブロックは庭に出さずに落とします）。

**最初のブロック（wood）と最初の部屋は無料**です。コインが1枚もない子が、
初日に何か作れないと意味がないので。

**D3 共有建築エリアは移していません。** Roblox でも別プレイスでした。
「みんなで同じ街を同時にいじる」は別の機能で、同期コストが桁違いです。
必要になったら、そのときに設計しましょう。
