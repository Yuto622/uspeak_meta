# 実機テスト チェックリスト（教室 Wi-Fi + iPad 実機 2台以上）

前提：Fly.io にデプロイ済み（`https://<app>.fly.dev`）、講師キーを1つ発行済み。
iPad は Safari（ホーム画面追加は不要）。1台目＝先生、2台目以降＝生徒として使う。

## A. 接続・基本同期

- [ ] A-1 iPad 1 で URL を開く → アバター選択 → ロビーに「なまえ」「クラスコード」を入れて参加。右上チップが「オンライン · 1人」になる
- [ ] A-2 iPad 2 で同じクラスコードで参加 → 両方のチップが「2人」になる（3秒以内）
- [ ] A-3 iPad 1 で歩く → iPad 2 に相手のアバターと名前ラベルが表示され、**滑らかに**追従する（ワープ・カクつきが無い）
- [ ] A-4 走る（Shift 相当は無いので歩きのみ）・止まるで相手の足のアニメが切り替わる
- [ ] A-5 同じ名前で3台目が参加しようとすると「その名前はもう使われています」と出る
- [ ] A-6 別のクラスコードで参加した端末は互いに見えない
- [ ] A-7 https のページから `wss://` で接続できている（Safari の Web インスペクタ、または「オフライン」にならないこと）

## B. 空間の切り替え

- [ ] B-1 iPad 1 が飛行機で別地域へ移動 → iPad 2 からは見えなくなり、iPad 2 も同地域へ行くと再び見える
- [ ] B-2 建物に入る → 外にいる相手からは見えない。同じ建物に入ると見える
- [ ] B-3 テーマパークへ移動しても同様

## C. iPad Safari の切断・復帰（最重要）

- [ ] C-1 iPad 2 でホームボタン → 10秒後に戻る → チップが「再接続中」→「オンライン」に **3秒以内** で戻り、相手からも消えていない
- [ ] C-2 画面ロック（電源ボタン）→ 30秒後に解除 → 同上。所持コイン・場所が保たれている
- [ ] C-3 画面ロック → 2分後（猶予60秒超）に解除 → 名前で再参加され、コイン・場所（2時間以内なら）が復元される
- [ ] C-4 Safari のタブを閉じずにアプリ切替で長時間放置 → 戻って自動復帰。ロビーが出ないこと
- [ ] C-5 ページを再読み込み → ロビーを出さずに自動で再参加する（sessionStorage）
- [ ] C-6 Wi-Fi を一度切って戻す → 自動再接続。「サーバーにつながりません」が出た場合、Wi-Fi 復帰後に自動で戻る
- [ ] C-7 iPad 1（先生）側で同じ C-1〜C-3 を行い、先生コンソールが復帰後も使える

## D. サーバー権威（コイン・正誤）

- [ ] D-1 英単語釣りで魚を釣り、店で売る → コインが増える。iPad をリロードしても同じコイン数
- [ ] D-2 わざと間違えた回答をする → 先生コンソールの「正解/回答」に反映（例 1/2）
- [ ] D-3 Google スプレッドシート `players` タブに名前・coins・correct/attempts が数秒〜10秒で反映される
- [ ] D-4 `learning_log` に 1回答=1行（timestamp, question_id, correct）が記録される
- [ ] D-5 `coin_log` に売却・購入が記録される
- [ ] D-6 Safari の開発メニューで localStorage の `uspeak-fishing-v1` の coins を書き換えてリロード → サーバーの値に戻る

## E. 講師機能

- [ ] E-1 講師キーを入れて参加した端末にだけ「👩‍🏫」ボタンが出る。生徒側には出ない
- [ ] E-2 「全員をここに集合」→ 生徒全員が先生の足元に瞬間移動し、トーストが出る
- [ ] E-3 生徒の「⤵」→ その生徒だけが移動する
- [ ] E-4 生徒の「📢」→ 生徒側にバナー「先生が呼んでいます」が出て、ボタンで先生のところへ行ける
- [ ] E-5 「チャットを一時停止」→ 生徒はフレーズを送れず、先生は送れる。再開で戻る
- [ ] E-6 生徒が別地域・建物内でも E-2 が効く（建物から自動退出して集合）
- [ ] E-7 誤った講師キーでは先生にならない（生徒として参加する）

## F. チャット

- [ ] F-1 💬 からフレーズを選ぶと、自分と相手の頭上に吹き出し（約4秒）とログに表示される
- [ ] F-2 連打しても 1.5 秒に1回しか送れない
- [ ] F-3 `phrases.json` を編集してデプロイすると新フレーズが出る（サーバー側も同じファイルを読む）

## G. 25人規模・運用

- [ ] G-1 `npm run loadtest -- --url=wss://<app>.fly.dev --clients=25 --duration=600` を教室 Wi-Fi 外から実行し、切断0・p95 遅延 < 300ms
- [ ] G-2 実機 2 台 + 負荷テスト 23 接続の混在で、実機の描画がカクつかない（iPad の描画：低品質トグルも確認）
- [ ] G-3 授業開始（全員が同時に URL を開く）で three.module.js（1.27MB）のロード時間を計測。遅い場合は事前に開いておく運用にする
- [ ] G-4 `GET /healthz` の cpuPercent / memory を授業中に記録する
- [ ] G-5 30人目以降（MAX_CLIENTS 超過）は「このクラスは満員です」と出る

## J. おつかいクエスト（AI英会話）

- [ ] J-1 オンラインで参加すると 🗣 ボタンが出る。オフラインでは出ない
- [ ] J-2 一覧が級ごとに並び、スタンプ数が表示される
- [ ] J-3 ミッションを始めるとキャラクターが英語で話しかけ、読み上げも鳴る
- [ ] J-4 マイクボタンで音声入力できる。許可しなくても文字入力で進められる
- [ ] J-5 お題が達成されるとチェックが付き、ヒントが日本語で出る
- [ ] J-6 クリアするとコインが増える。リロードしてもコインとスタンプが残る
- [ ] J-7 先生コンソールの「今日のおつかい」を選ぶと、生徒の画面の一番上に出る
- [ ] J-8 会話が Google スプレッドシートの `learning_log` に1発話1行で記録される
- [ ] J-9 連打しても1.2秒に1回しか送られない
- [ ] J-10 ミッション中に画面をロックして戻っても、会話を続けられる

## I. スマホでの表示（iPhone などで使う場合）

- [ ] I-1 縦向きで、画面下の移動ボタン（↑←↓→）が指で押せる位置に出ている
- [ ] I-2 画面下のメニュー（冒険・単語帳・島の地図・広場へ）が全部見えている。下端で切れていない
- [ ] I-3 右側の「RPGワールドマップ」「英単語釣り」「冒険ノート」が全部見えて押せる
- [ ] I-4 端末を横向きにしても、上の3つが画面外に消えない
- [ ] I-5 左のクエスト一覧が長くても、移動ボタンに重ならない（パネル内でスクロールする）
- [ ] I-6 💬 チャットを開いてもフレーズが読める。狭い画面では1列で並ぶ
- [ ] I-7 ノッチのある機種で、上下の表示が切り欠きやホームバーに隠れない
- [ ] I-8 接続状況の表示が「● 3人」の形で、他のボタンに重なっていない

## H. 既知の制約（テストで確認するのではなく共有事項）

- 問題の生成はクライアント側。データファイルを読める人が常に正解を選ぶことは防げない（正誤・コインの改ざんは防いでいる）
- 音声チャット（WebRTC）と AI 対話はスコープ外
- Google Sheets の書込は最大 5 秒遅延する。シート側を手で編集してもサーバーのメモリには反映されない（次回接続時に読み込む）
