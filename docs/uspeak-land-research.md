# 「自分だけの島」の類似事例リサーチ — 土地島の土台

土地島（U-Speak Web の新しい島：コインで自分だけの島を買い、コインで豪華にしていく）を作る前に、
**「自分の土地・家を買って育てる」を売りにしているゲームが、段階と値段をどう決めているか**を並べた。
ここに書いた数字と結論が、`land.json` の 6 段階と値段の根拠。出典は末尾。

## 0. 結論（先に）

| 決めたこと | 根拠（下の章） |
|---|---|
| **段階は 6 つ**、見た目のテーマが毎段ちがう（砂浜 → 草原 → 森 → 花 → 雪 → 空の城） | どのゲームも「広さ」だけでは続かず、**テーマが変わる段階**がいちばん覚えられている（§1 ACNH の家の外観、Adopt Me の家の種類） |
| **1 段目は 100 コイン＝初日に買える** | 「最初の家は無料か、初日に手に入る」が共通（Stardew の家、Adopt Me の Tiny Home、ACNH のテント）。持っていない子を作らない |
| **段階ごとに約 2.5 倍**（100 → 600 → 1,500 → 4,000 → 10,000 → 25,000） | ACNH のローンは 1.5〜2 倍、Stardew は 5 倍→2 倍、Adopt Me は 2〜5 倍。**2〜3 倍**が「次が見える」距離（§4） |
| **最上段は数か月の目標** | 週 1〜2 回の教室で 1 回 200〜400 コインなら、25,000 は 4〜6 か月。ACNH の最後のローン（249.8 万ベル）も現実には数か月（§1） |
| **強さは買えない**。豪華さだけ | 「上の島の子が英語で有利」になると、教室に見せられない。どのゲームも家は見た目と広さだけ（§4） |
| **順番に買う**（飛ばさない）、**戻らない** | 家の増築と同じ。段を飛ばせると「貯めてから一気に」になり、途中の島を見る機会が消える |
| **島の中は歩ける 3D の自分の場所**、他の子は 土地島の「みんなの しま」の板で見る | 見せる相手がいないと買わない（Bloxburg・Adopt Me の「友だちの家に行く」）。まずは板、訪問はあとから |

## 1. 事例

### あつまれ どうぶつの森（Nintendo, 2020）
- 最初は**テント**（無人島移住パッケージ 49,800 ベル。**マイルで払える**ので「初日に払える」）。
- 家のローン：98,000 → 198,000 → 348,000 → 548,000 → 758,000 → 1,248,000 → 2,498,000 ベル（合計約 570 万）。
  **隣り合う段の比は 1.4〜2.0 倍**。
- 家は「増築」のたびに**外観の選択肢**（屋根・壁・ドア）が増える。遊んだ人が覚えているのは「ベルの額」より
  「2 階ができた」「地下ができた」という**形の変化**。
- 島そのものは買わない。かわりに**橋（98,000〜228,000）・坂（128,000〜228,000）**を公共事業として買う。
  → 「土地の豪華さ」はこのゲームでも**買う**もので、支払いは共同（寄付）。
- ローンは**無利子・返済期限なし**。「払えないと困る」をなくしているのが、子どもが続けられた理由として挙げられる。

### Stardew Valley（ConcernedApe, 2016）
- 家の増築：10,000G + 木材 450 → 50,000G + 硬木 150 → 100,000G（地下室）。**5 倍 → 2 倍**。
- 1 段目は序盤の 1 週間、2 段目は春の終わり〜夏、3 段目は 1 年目の終わりごろ、というのが典型的な体験談。
  **1 年（ゲーム内）で最後まで届く**ように値段が組んである。
- 増築は「結婚できる」「料理できる」という**機能**も開く。→ U-Speak では機能を縛らない（§4）。

### Roblox Adopt Me!（Uplift Games）
- 家の種類と値段（バックス）：Tiny Home **無料** / Family Home 500 / Pizza Place 7,500 / Treehouse 5,000 /
  Modern Mansion 30,000 / Celebrity Mansion 60,000 / Futuristic House 100,000 / Castle 120,000 ほか。
- 1 日の稼ぎは数百バックス（ペットの世話・ログイン）。**最安が初日、最高が数か月**。
- 「家」は**テーマ**で選ぶ（ツリーハウス・城・未来の家…）。大きさの段階ではなく、**ちがう世界**を買う。
  これが「次はどれにしよう」の会話を生む。U-Speak の 6 段のテーマ分けはここから。

### Roblox Welcome to Bloxburg（Coeptus）
- 土地は最初から 30×30。広い土地は Robux（有料）。家は家具 1 つずつ買って建てる（1 つ数十〜数千）。
- **友だちの家を見に行く**ことが遊びの中心。見せる相手がいるから建てる。
  → U-Speak は、まず 土地島の「みんなの しま」の板で**クラスの島の段階を並べて見せる**（順位ではなく「いまどこ」）。

### Roblox Islands（Easy.gg）
- 自分の島の**拡張**を段階で買う：2,500 → 10,000 → 25,000 → … コイン（**約 2.5〜4 倍**）。
  最初の拡張は 1 時間ほど、最後は数十時間。
- 「広さ」だけだと途中で飽きる、という声が多い。→ 広さにテーマを重ねる。

### 牧場物語（本リポジトリの `uspeak-farm-research.md`）
- 家の増築 5,000G → 10,000G（ミネラルタウン）。増築で**ベッド・台所**が増える。
- 「畑が整っていくのが目に見える」ことがモチベーション。→ 島も**歩いて見られる**こと。

## 2. U-Speak のコインの実態（値段を合わせる相手）

| もらえるところ | 1 日の上限 | ふつうの 1 回（教室 40 分） |
|---|---|---|
| ログインボーナス | 100〜400（7 日周期） | 100〜400 |
| ぼくじょう島の出荷 | 150 | 30〜100 |
| 英検の島 | 150 | 50〜150 |
| 英会話島 | 200 | 40〜80 |
| のりもの島・グランプリ | 220 | 50〜150 |
| つり | 上限なし（魚の値段） | 30〜100 |

**教室の子は週 1〜2 回・1 回 200〜500 コイン**（= 月 1,500〜4,000）。家では毎日ログインする子もいる（月 6,000〜10,000）。

既にある値段：きせかえ 40〜600、のりもの 100〜3,000、マイルーム 0 / 800 / 2,500。
島はこれらより**上の目標**として置く（のりものの最高 3,000 より上に 3 段ある）。

## 3. 6 段階（`land.json`）

| 段 | 島 | 値段 | 届くころ（教室の子） | 見た目 |
|---|---|---|---|---|
| 1 | すなはまの しま（Sandy Islet） | **100** | 初日 | 砂、ヤシ 2 本、テント、たき火、ヒトデ |
| 2 | くさはらの しま（Grassy Isle） | **600** | 2〜3 週 | 草原、木の小屋、さく、木 3 本、花だん、犬小屋 |
| 3 | もりの しま（Forest Isle） | **1,500** | 1〜2 か月 | 森、丸太の家、池と桟橋、ランタンの道、ブランコ |
| 4 | はなの しま（Flower Isle） | **4,000** | 2〜3 か月 | 花畑、赤い屋根のコテージ、風車（まわる）、噴水、ベンチ、旗 |
| 5 | ゆきの しま（Snow Isle） | **10,000** | 4〜6 か月 | 雪、ロッジ（煙突のけむり）、雪だるま、光るモミの木、こおりの池 |
| 6 | そらの しま（Sky Castle） | **25,000** | 半年〜1 年 | 雲の上、城と塔、にじの橋、金の門、像、星 |

- 比は 6.0 / 2.5 / 2.7 / 2.5 / 2.5。1→2 だけ大きいのは、1 段目を「初日」に置いたため。
- 広さも 14 → 16 → 18 → 20 → 22 → 24 マスと増えるが、**見た目のテーマが主**。
- **レベル条件は付けない**（コインだけ。ユーザーの指示）。マイルームはレベル条件あり（4・8）だが、島はそれと役割がちがう。

## 4. 守ること（設計の約束）

1. **英語の強さ・コインの稼ぎに影響しない。** 島はごほうびで、学習の記録とも無関係。
2. **順位表にしない。** 「みんなの しま」はクラスの子の島を**段の順ではなく名前の順**で並べ、段を絵で見せる
   （`docs/uspeak-retention.md` の「順位は下の子の保護者に見せられない」）。
3. **買うときは必ず確認**（「◯◯の しまに する？ ◈ 600」）。子どもが眺めているだけで減らない。
4. **サーバーが決める。** 値段・段・コインの引き落としは `server/src/game/land.js`。ページは `land.json` を同じく読んで並べるだけ。
5. **保存は `land_json` 1 列**（`{tier}`）。段しか持たないので、家具のように消える心配がない。
