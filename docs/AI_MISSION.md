# おつかいクエスト（AI英会話ミッション）

**おつかい島**を歩いてやる「おつかい」です。広場でおつかいを受け、お店まで歩いて英語で話し、
広場まで持ち帰ってはじめてコインとスタンプがもらえます。子どもは AI 相手なので、
まちがえても恥ずかしくありません。

## 歩かないと終わらない

ボタンだけでは完了しません。3つの区間はすべて、**アバターがその場所に立っていること**を
サーバーが確認してから進みます。

```
① おつかい広場のミアに話しかける      → おつかいを受け取る（英語の依頼＋日本語字幕）
        ↓ 歩く（17〜33メートル）
② お店の人に英語で話しかける          → お題を全部クリアすると「品物」を受け取る
        ↓ 歩いてもどる
③ 広場のミアにとどける                → ここではじめてコイン＋スタンプ
```

一覧（🗣ボタン）でおつかいを選んでも、それは**行き先が決まるだけ**です。会話は始まりません。
画面左のトラッカーが「つぎにどこへ行くか」を出し、その場所には光の柱が立ちます。

## 仕組み

```
子ども → おつかい島のその場所まで歩く
          ↓ 英語で発話（マイク or 文字）
       サーバー（Colyseus）
          ↓ 位置を確認 → AI に判定を依頼
       AI が「返事」と「どのお題が達成されたか」を返す
          ↓
       サーバーが達成・報酬・学習ログを確定
          ↓
       クライアントは受け取った結果を表示するだけ
```

**判定と報酬はすべてサーバーが決めます。** クライアントが「クリアした」と申告しても無視され、
AI が返した内容もサーバー側で検証されます。存在しないお題IDは捨てられ、一度達成したお題は取り消されず、
「全部のお題が達成された時だけ完了」をサーバーが計算し直します。保護者向けレポートの数値元になるためです。

場所の確認も同じサーバーが、コインを渡すのと同じ場所で行います。広場から離れて `mission:start` を
送っても、お店から離れて `mission:say` を送っても、`too far` で断られます。

> **正直に書いておくこと：** 座標はクライアントが申告します（これは元の仕様どおりで、移動には
> チート対策を入れていません）。つまり改造したクライアントなら瞬間移動できます。ただし申告した
> 座標は**同じクラスの全員に見えている座標**でもあるので、瞬間移動すれば教室の他の子の画面で
> ワープして見えます。ここで守っているのは「メニューだけで終わらせられない」というゲームの
> ルールであって、不正の完全な防止ではありません。

## 起動に必要な設定

API キーはサーバーの環境変数にだけ置きます。**クライアントには一切渡りません。**

```powershell
# ローカル（server/.env）
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
```

```sh
# Fly.io
fly secrets set OPENAI_API_KEY='sk-...'
```

`OPENAI_MODEL` は使いたいモデル名を設定してください。モデル名と料金は提供元で変わるので、
授業で本格運用する前に現行の名前と単価を確認してください。

**キーを設定しない場合も機能は動きます。** その場合は台本パートナー（決まった返事・キーワード判定）に
なり、API 料金はかかりません。動作確認や、予算を決める前のデモに使えます。

## コスト管理

| 環境変数 | 既定 | 役割 |
|---|---|---|
| `AI_MAX_TOKENS` | 300 | 1返答の上限。返事は1〜2文なので十分 |
| `AI_MIN_INTERVAL_MS` | 1200 | 連打防止。1.2秒に1回まで |
| `AI_DAILY_TURNS_PER_STUDENT` | 200 | 1人1日の発話上限 |
| `turnLimit`（missions.json） | 12 | 1ミッションの往復上限 |

1ミッションは最大12往復で打ち切られます。上限をすべて使い切っても、1回の会話で送る量は
システムプロンプト約530トークン＋会話履歴に収まります。

## おつかい島

`client/dist/missions.json` の `island` が島の定義です。クライアントはこの座標で島を建て、
サーバーは同じ座標で「その場に立っているか」を判定します。ずれようがありません。

| 場所 | 住人 | 役割 |
|---|---|---|
| おつかい広場 | Mia | おつかいを渡す／受け取る。全ミッションの起点と終点 |
| Sunny Bakery | Oliver | お店 |
| Village Square | Emma | お店 |
| Bluewater Harbor | Luna | お店 |
| Whispering Forest | Finn | お店 |
| Tide & Thread | Emma | お店 |
| The Explorer's Inn | Luna | お店 |
| Forest Library | Finn | お店 |
| Wonder Park Gate | Oliver | お店 |
| Island Museum | Emma | お店 |

島へは「✈ RPGワールドマップ」か、おつかい一覧の「✈ おつかい島へ行く」で飛びます。

判定の半径は `island.radius`（5メートル）＋サーバー側の余裕 1.5 メートルです。
起動時に「どの2つの場所も `radius × 2` より離れていること」を検証しているので、
1か所に立って2か所ぶんを兼ねることはできません。

## ミッションを増やす・直す

`client/dist/missions.json` を編集するだけです。サーバーも同じファイルを読むので、
子どもに見える文言と判定基準がずれません。

```json
{
  "id": "cafe-order-2",          // 変更しないこと（学習記録がこのIDで紐づきます）
  "grade": "5",                   // 5 / 4 / 3 / 準2 / 2
  "title": "カフェで飲み物を2つ注文しよう",
  "character": "Oliver",          // 既存キャラ: Emma / Oliver / Luna / Finn
  "place": "Sunny Bakery",        // island の spot 名と一致していること
  "spot": "bakery",               // 英語で話す場所（島の spot id）
  "from": "plaza",                // 受け取り・とどけ先。spot と別の場所であること
  "item": "two drinks",           // 持ち帰るもの。トラッカーに出ます
  "request": "Could you go to ...",     // 英語。広場のミアの依頼
  "requestJa": "サニーベーカリーで…",     // 日本語字幕
  "thanks": "Two drinks — perfect...",  // 英語。とどけたときのひとこと
  "situation": "You are Oliver, ...",   // 英語。AIへの役割説明
  "opening": "Good morning! ...",       // 英語。最初のひとこと
  "goals": [
    { "id": "ask", "ja": "飲み物をたのむ", "en": "The child asks for a drink." }
  ],
  "hints": ["I'd like a juice, please."], // goals と同じ数だけ。台本モードの判定にも使います
  "reward": 30
}
```

サーバー起動時に検証されます。ID重複・級の誤り・目標なし・報酬の異常に加えて、
**`spot` と `from` が同じ場所（＝歩かなくても終わる）**、`character` や `place` が
その場所の住人と食いちがう、島の場所どうしが近すぎる、といった場合もエラーになって起動しません。
壊れたまま授業が始まることはありません。

## 子どもの安全のために入れていること

- キャラクターを崩さない。自分がAIだと言わない
- 氏名・学校・住所・電話・家族構成を聞かない。子どもが言っても繰り返さない
- 英語のまちがいを否定しない。意味が取れれば受け止めて、正しい言い方を返事の中で自然に示す
- 級ごとに語彙と文の長さを制限する（5級なら8語以内の現在形など）
- 返事の長さを240文字、ヒントを80文字で切る
- 全発話を `learning_log` に記録する。先生が後から読めます

## 授業での使い方

先生コンソール（👩‍🏫）の「今日のおつかい」から選ぶと、クラス全員の画面の一番上に
そのミッションが表示されます。指定しない場合、子どもは一覧から自由に選べます。

## 記録の見かた

| シート | 記録されるもの |
|---|---|
| `learning_log` | 1発話 = 1行。`question_id` が `mission:<ID>`、`choice` に子どもが言った英文、`correct` はその発話でお題が進んだか |
| `coin_log` | クリア報酬。`op` が `award`、`item` が `mission:<ID>` |
| `players` | `missions_json` にクリア済みミッション（スタンプ） |

## 制約

- 音声認識はブラウザの機能を使います。iPad Safari では毎回タップが必要で、認識精度は端末に依存します。文字入力でも同じ報酬が得られます
- 発音の採点はしていません。判定しているのは「意味が伝わったか」です
- オンライン接続時のみ遊べます。オフライン1人用モードでも島は歩けますが、おつかいは受け取れません
- 1往復あたり 17〜33 メートル歩きます（歩き 5m/s、Shift で 8m/s）。1つのおつかいで往復2回、
  だいたい 20〜40 秒が移動時間です。授業の残り時間が少ないときは、広場に近い
  Village Square・Sunny Bakery・Bluewater Harbor のおつかいを指定してください
