U-Speak Web版　全島リスト

26の島 と ぼうけんの ちいき 10こ。⭐ は プレミアム（名簿で プレミアムが オンの 人だけ 入れる）。

はじまりの 島

1メインの島Main Island

  • 入ると さいしょに 立つ ホームの 島
  • 英単語ハウス 3けん（4たくの 単語クイズ・SUPER EASY / EASY）
  • つり場と、英検の 級ごとの さんばし（5級〜準1級）
  • 屋台 3つ（くだもの・スイーツ・のみもの）で たべものを かう
  • ふくや・ブロックや・いえの おみせ・ぶきや（100本）・さかなの かいとりや
  • 英会話の お店 5けん（けいたいや・でんきや・ほんや・ピザや・バーガーや）⭐
  • ほかの 島への ゲート、2D の しまの ちず

2U-Speak島U-Speak Island

  • メインの島から 木の 橋で 歩いて わたれる
  • 英語の クイズに こたえる さかなつり（100匹の ずかん）
  • パンや・図書室・やどや などの 建物に 入れる
  • 公園の ロビー（なかまの 回復・魔法の 杖・伝説の 書）
  • レッスン、ひるよるの 時計と BGM

学ぶ 島

3ABC の 島ABC Island

  • もじの なまえと おと（フォニックス）
  • 見て きく → うた → きいて えらぶ → 絵を えらぶ
  • 3もじを つなげて よむ、2もじの おと、ながい ぼいん、つみきで つづる
  • 8わりで つぎへ、にがての ふくしゅう

4よみもの島Book Island

  • えほん 36さつ（12だんかい × 3）
  • きく → よむ → こえに だす → クイズ 5もん
  • ことばを おすと 発音と いみ
  • 先生が えほんを 宿題に できる

5ことばの学校島Word School Island

  • 3つの 小屋の 単語クイズ（やさしい〜むずかしい）
  • ことばの ジム（きく・かく・はなす、110語）

6しゅくだい島Homework Island

  • 先生が くばった 宿題を 7つの 形で とく（えらぶ・つづり・きいて えらぶ・タイピング・せんつなぎ・ならべかえ・あなうめ）
  • とちゅうから つづけられる、まちがえた ところを やりなおせる
  • 結果は 保護者レポートに のる

7〜13英検の島（5級・4級・3級・準2級・2級・準1級・1級） ⭐ プレミアムEiken Islands

  • 4つの 館＝4技能（よむ・きく・かく・はなす）
  • めんせつの間（二次試験の 練習。音読 → 質問、ウーピーが 面接官）
  • はんていの きびしさは 先生が 3だんかいで きめる
  • 7つとも 同じ 間取りで、英語と 見た目だけ かわる

14英会話島 ⭐ プレミアムConversation Island

  • 4つの 家＝8つの 場面で、ウーピーと AI英会話
  • マイクで はなす、こたえの れい、ゆっくり、いみ
  • おわりに ふりかえり（言えた 文・もっと いい 言いかた）

15おつかい島Errand Island

  • 広場で うける → お店で 英語で はなす → とどける、の 3だんかい
  • とどけたら コイン

あそぶ 島

16つり島Fishing Island

  • いけ（5級）・かわ（4級）・うみ（3級）の 3つの 水辺
  • 水辺に 立つと さおを なげ、7つの 形の 問題に 正解で つれる
  • さかな 70しゅるいの ずかん、うる

17えいごアリーナ島Word Arena Island

  • 3D の 対戦画面で マスターウーピーと バトル
  • 強い わざは 英語の 問題に 正解しないと 出ない
  • 道場（つった さかなが わざに なる）

18ペット島Pet Island

  • たまごを かえす、ごはん、なでる
  • ペット（こいぬ・こねこ・うさぎ・かえる・パンダ・きつね）が どの 島でも 横を 歩く

19のりもの島Ride Island

  • ガレージで のりものを かう
  • グランプリ（クラスの みんなと ライバルで 3しゅうの レース、📦は 英語の 3たく、正解で 加速）
  • AURORA KART（べつの カートゲーム。うんてんしゅは じぶんの アバター）

20ぼくじょう島Farm Island

  • たねを かう・うえる・水やり・しゅうかく・出荷・料理
  • どうぶつの せわ（エサ・みず・ブラシ）
  • どの さぎょうも 英語の 問題に こたえて する
  • 季節・天気・おまつり・住人との なかよし度

21ミニゲーム島Minigame Island

  • PUYO U-SPEAK（ぷよ × 英単語）
  • えいご スイカゲーム

22テーマパークWonder Park

  • メリーゴーランド・かんらんしゃ・ジェットコースター（のる たびに コイン）

つくる・かざる 島

23まちづくり島Town Island

  • かぐを かって じぶんの へやに おく
  • ブロックを かって ひろばに 建てる
  • BLOCKWILD（ブロックの 世界。クラスで 同じ 世界に 入れる）

24土地島Land Island

  • ふどうさんで じぶんだけの 島を かう（6だんかい × 2しゅるい、12の 世界）
  • 船で じぶんの 島へ、みんなの 島を 見に いける

25きせかえ島Dress-up Island

  • 5つの 店（ぼうし・めがね・かばん・アクセサリー・すがた）
  • かった ものは クラスの みんなに 見える

はなす 島

26みんなで はなす しま ⭐ プレミアムTalk Island

  • 島ぜんたいが 1つの 通話（100人まで）
  • ビデオ通話、画面共有、定型文の メッセージ
  • ブースは 6人までの 小さい 部屋

ぼうけんの ちいき（10こ）

ことばの草原ささやきの森水晶のサンゴ礁夕映えの渓谷白銀の峰風鳴りの高原黄金の砂丘星時計の遺跡月影の庭天空の聖域
  • なかまの モンスターを つかまえる・そだてる、ずかん
  • 物語、ちいきの リーダーと リーグ
  • 宝箱 36こと 3しゅるいの 鍵

  • ロードマップ（A・B・C・1〜9 の 12だんかい、英検の 合格見込み）
  • ランキング、たんごちょう、もちもの、にがて単語の ふくしゅう
