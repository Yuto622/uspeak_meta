# 製品として 出せる 安全性か — 基準に 照らした 検査（2026-10-20）

対象：Web 版 U-Speak（`server/` + `client/dist/`、Fly.io 上の https://uspeak-multiplayer.fly.dev）。
照らした 基準：
- OWASP ASVS 5.0（2025-05）と OWASP Top 10 — Web アプリの 認証・セッション・アクセス制御・入力・暗号・ログ の 検証項目
- IPA「安全なウェブサイトの作り方」改訂第7版 — 日本の 標準的な 実装チェック（11 の 脆弱性・7 の 運用）
- 文部科学省「教育情報セキュリティポリシーに関するガイドライン」（令和7年3月 改訂）— 学校で 使う クラウドの 考え方（アクセス制御・利用者認証・外部サービス）
- 個人情報保護法（令和8年 改正：16 歳未満の 子どもの 個人情報の 規律が 新設。政令・ガイドラインは 2026-09 時点で 検討中）、個人情報保護委員会の 公表資料
- 子ども向けサービスの 一般的な 慣行（COPPA / Google Play ファミリー・Apple Kids の 考え方：最小限の 収集・第三者送信の 開示・保護者の 関与）

結論は 最後の「判定」に。

## 1. 認証・権限（ASVS V6/V7/V8、IPA 1-7・1-8、文科省「利用者認証」）

| 項目 | 2026-10-19 まで | いま | 根拠 |
|---|---|---|---|
| 先生の 権限 | 名簿の「先生か」だけで 先生に なれた（名前を 知れば だれでも） | **名簿の あいことば（pin）が 必須**。合わなければ 入室も できない。講師キーは いままでどおり | ASVS 6.x：権限の ある 役割には 認証を 要求 |
| 子どもの なりすまし | クラスの あいことば＋名前で その 子に なれた | 名簿の 行に あいことばを 書いた 子は、ロビーで「じぶんの あいことば」が 必要（open モードでも） | ASVS 6.x、文科省：個人の 記録には 本人確認 |
| 総当たり | admin ログインだけ 制限、しかも `trust proxy` の 設定で すり抜け可 | `trust proxy 1` に 修正、入室は 1 IP 1 分 120 回、レポート系の 口は 1 分 120 回 | ASVS 6.3、IPA 1-7 |
| 管理画面 | 1 つの ADMIN_KEY、Cookie は HttpOnly/SameSite/Secure（本番）、CSRF ヘッダー | 同じ（https なら 開発でも Secure） | ASVS 7.x |
| 署名つき リンク（保護者レポート・教室の ようす・CSV） | 期限なし・個別に 無効化 できない | **期限つき**（保護者 180 日・教室/CSV 30 日）。古い 形は 2027-01-31 まで 受けつけ、その後は 取りなおし | ASVS 7.2 / 3.x |
| セッション | Colyseus の 再接続トークン、先生の 鍵は localStorage に 残っていた | localStorage から 外した（sessionStorage のみ） | ASVS 7.4 |

## 2. 入力・出力・通信（ASVS V5/V12/V13、IPA 1-1〜1-6、1-9〜1-11）

| 項目 | 状態 |
|---|---|
| XSS | 画面は `esc()` で 書く。CSP を 追加（script は 自分と インライン、外部は LINE SDK だけ、frame-ancestors は 自分、object なし） |
| インジェクション | DB は JSON ファイル／Google Sheets（SQL なし）。シートの 値は 文字列として 書く |
| 入力の 大きさ | 本文は 1〜16 KB、名前 16 文字、チャット 120 文字、AI の 発話 200 文字、Roblox の できごと 32 KB |
| 通信 | HTTPS 強制（Fly）、HSTS、WSS、CORS は 許可リスト、WebSocket も Origin を 見る |
| ヘッダー | HSTS・nosniff・X-Frame-Options・Referrer-Policy・Permissions-Policy・COOP・CSP |
| エラー | スタック・パスを 返さない 共通の エラーハンドラー |
| 依存ライブラリ | `npm audit fix` で 重大 1（proxy-addr の IP 偽装）・高 2（compression・brace-expansion）を 解消。残り 12 件は Colyseus 0.15 系の 推移的な 依存（uuid・nanoid・qs など。サーバーの 入口には 届かない 経路で、0.16 への 更新は 別作業） |

## 3. 個人情報（個人情報保護法・文科省・子ども向けの 慣行）

| 項目 | 状態 |
|---|---|
| 収集の 最小化 | 名前（ニックネーム推奨）・クラス・学習の 記録・保護者の LINE ID のみ。住所・電話・メール・生年月日・顔・録音は 集めない |
| 目的と 第三者提供の 開示 | `/privacy.html`（OpenAI・LINE・LiveKit・Google・Fly・ブラウザーの 音声認識を 明記） |
| 外部へ 出る 前の そうじ | OpenAI には 名前・クラスを 送らず、電話番号・メール・URL・SNS ID を 消してから |
| 保持期間 | 学習ログ・コインログ・送信記録 400 日、レポートの ファイル 60 日、止めた 紐づけ 30 日 |
| 削除の 権利 | /admin「この 子の 記録を 消す」と CLI |
| ログ | 名前・IP は 鍵つきの 札。生の 名前は `LOG_PII=1` の ときだけ |
| 保護者の 同意 | LINE の 同意画面（ポリシーへの リンクつき）。**学校経由の 同意書の ひな形は 未作成**（下の「残る 課題」） |
| 子どもどうしの 安全 | 連絡先の 交換・傷つける 言葉を サーバーで 止め、先生が 確認できる。先生が 自由入力を 止められる |

## 4. 運用（ASVS V1/V14、IPA 2 章、文科省「運用」）

| 項目 | 状態 |
|---|---|
| 秘密の 管理 | すべて `fly secrets`。リポジトリに 秘密・名簿なし（履歴も 確認） |
| バックアップ | **なし**（Fly の ボリューム 1 つ）。日次の スナップショットを 入れること（Fly volumes snapshots は 自動で 5 日分 あるが、復元手順が 未確認） |
| 監査ログ | 先生の 操作・admin の 削除は ログに 残る（札で） |
| テスト | 424 件の 自動テスト（認証・権限・判定・個人情報）＋ 実ブラウザの e2e |
| インシデント対応 | **手順書なし**（連絡先・初動・保護者への 通知の 文面） |

## 5. 今回 直した もの（コード）

1. 名簿の あいことば（pin）列：先生は 必須、子どもは 任意。ロビーに「じぶんの あいことば」。admin の 表・CSV・Google シート（F 列）に 列を 追加
2. 入室の 総当たりの 守り（1 IP 1 分 120 回、`JOIN_PER_MIN`）
3. 署名つき リンクの 期限（`LINK_TTL`、猶予 `REPORT_LINK_LEGACY_UNTIL`）
4. CSP・共通の エラーハンドラー・https なら admin Cookie に Secure
5. 依存ライブラリの 更新（重大 1・高 2）

## 6. 残る 課題（出す 前に 決める・用意する）

| 優先 | 課題 | 目安 |
|---|---|---|
| 高 | **バックアップと 復元の 手順**（store.json・parent-reports.json・roster.json を 日次で 別の 場所へ。復元を 1 回 試す） | 半日 |
| 高 | **保護者向けの 同意書・学校向けの 説明書**（個人情報保護法の 改正で 16 歳未満の 規律が 入る。学校経由で 保護者の 同意を とる 文書） | 1 日 |
| 高 | 先生の 行に あいことばを 入れる 運用（いま 名簿に ある 先生は、入れるまで 講師キーで 入る） | 教室ごと 5 分 |
| 中 | `TEACHER_KEY` が 全クラス 共通。教室が 増えたら クラスごとの 鍵か、名簿の あいことばだけに する | 数時間 |
| 中 | インシデント対応の 手順書（だれに・いつ・何を 伝える） | 半日 |
| 中 | Colyseus 0.16 への 更新（残りの 依存の 警告を 消す） | 1 日＋検証 |
| 中 | Google Fonts の 自前配信、TURN サーバー（IP が Google に 出ない ように） | 数時間 |
| 低 | CSP の `unsafe-inline` を なくす（インラインの script を 外に 出して nonce に） | 数時間 |
| 低 | 外部の 脆弱性診断（第三者に 1 回 見てもらう） | 外注 |

## 判定

**教室での 利用（先生が 見ている 場で、ニックネームで 使う）には 出せる 水準**。
認証・権限・入力・通信・ヘッダー・個人情報の 取り扱いは、OWASP ASVS の レベル 1 と IPA の 実装項目を 満たし、子ども向けの 慣行（最小収集・開示・削除・第三者送信の そうじ）も 備えた。

**保護者が 家庭で 本名で 使う 製品として 広く 出す なら、上の「高」の 3 つ（バックアップ・同意書・先生の あいことばの 運用）を 先に**。
これらは コードでは なく 運用と 文書で、どれも 1 日 以内。
