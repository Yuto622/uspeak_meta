# ゲーム要素と別プラットフォームの徹底リサーチ — Web 版に次に入れるもの

社内メモ（2026-10）。前の2本（`docs/uspeak-retention.md`＝継続の仕組み、`docs/uspeak-moat-2.md`＝
競合と引き離す記録の層）の続き。今回は **「ゲームとして何を足すか」** と **「どこに広げるか」** を、
競合・学習科学・日本の事情の3方向から調べた。出典は末尾。

---

## 0. 結論（先に）

**足すべきものは「島を増やす」ではなく、次の5つ。** どれも固定費（AI を使わない）で、
今あるサーバーの採点・記録にそのまま乗る。

| 順 | 何を足すか | 一言で | いちばん強い根拠 |
|---|---|---|---|
| 1 | **先生が始める「クラス協力レイド」**（全員で1体のボスを英語で削る、15分） | Blooket／Gimkit を授業に | 教室で実際に使われている形（Blooket 15以上のモード・Gimkit の Boss Battle）。協力型は競争型より行動面の成果が高い（Sailer & Homner 2020） |
| 2 | **まちがいノート＋間隔反復**（全部の島の「まちがえた問題」が、日をあけて戻ってくる） | 忘れたころに、もう一度 | 間隔練習は250以上の研究で一貫して効果。子どもの語彙でも1週間後まで差が残る |
| 3 | **教室の単語リストを取り込む**（先生が教科書・単語テストを入れると、全部のゲームに流れる） | 教室が中身を作る | 教室が入れた中身は移せない＝いちばん強い乗り換えコスト。Blooket・Gimkit が伸びた理由もこれ（中身は先生、遊び方はツール） |
| 4 | **2人で解く「伝えあいパズル」**（片方だけが答えを見ていて、英語で伝える） | マルチプレイでしか作れない | 第二言語教育の定番（インフォメーションギャップ・ジグソー）。協力が必要なゲームで学習成果が上がった研究（Crystallize） |
| 5 | **クラスの「みんなのメーター」と月替わりイベント**（順位のかわりに、クラスで目標に届く） | 毎月、戻ってくる理由 | Roblox の継続を支えているのは期間限定イベント。順位表は下位の子を傷つける研究が多い |

**逆に、やめる／変えるもの**：週間ランキングの「トップ10」表示（小さい教室では下位の子が
名指しになる）、有料の「会員限定」要素、子ども同士のトレード、発音の厳しい機械採点。

**広げる先**は、①**LINE で保護者に月次レポートを届ける**（いちばん効く）、②**ホーム画面に置ける
Web アプリ（PWA）**、③**フランチャイズ本部への提案**（ECC ジュニア約14,000教室・BE studio 約1,700教室）。
Minecraft Education・ネイティブアプリ・Google Classroom 連携は今はやらない（理由は6章）。

## 1. いま Web 版にあるもの（棚卸し）

足すものを決める前に、重複を避けるために数えた。

| 種類 | すでにあるもの |
|---|---|
| 島 | はじまりの島、おつかい島（歩く AI 英会話）、ことばの学校（単語クイズ小屋）、ジム（きく・はなす）、アリーナ（バトル）、道場、ペット島、まちづくり島（ブロック・自分の部屋・ひろば）、のりもの島（カート・グランプリ）、英検5・4・3級の島（4技能の館＋面接の間）、おはなし島（通話）、英会話島（AI）、きせかえ島、ミニゲーム島（ぷよ・スイカ）、BLOCKWILD |
| 集める | 魚100種（1匹＝英単語1つ）、なかま100体（オフラインRPG）、のりもの、服、家具・ブロック |
| 毎日・毎週 | ログインボーナス（7日周期）、**週間XPランキング（トップ10）**、季節、夜のおばけ、今日の5ふん |
| 復習 | **オフラインRPGの中にだけ**間隔反復がある（`adventure-data.js` の `box`・`due`）。サーバーの採点・記録とはつながっていない |
| 先生 | 集合・呼び出し・移動、チャット停止、じゆうにゅうりょく、通話の範囲、英検のきびしさ、今日のおつかい、名簿、気づき、声かけ、メモ、レポート、CSV、教室のようす |

**足りないもの**は4つに分けられる：①**授業中にクラス全員で遊ぶモード**が無い（今あるのは
各自がばらばらに遊ぶもの）、②**復習がサーバー側に無い**、③**教室が中身を入れる口が無い**、
④**子ども同士が英語でやりとりしないと進まない仕掛け**が無い（通話とチャットはあるが、
使わなくても進める）。

## 2. 競合・類似プラットフォームから学ぶこと

| プラットフォーム | 何が強いか | 学ぶこと | まねしないこと |
|---|---|---|---|
| **Blooket** | 同じ問題セットで15以上の遊び方（タワーディフェンス・ゴールドクエスト・カフェ・つり…）。小中学校で特に強い | **中身（問題）と遊び方を分ける。** 飽きたら遊び方だけ替える | — |
| **Gimkit** | 答えて稼いだお金で強化を買う戦略性。**Boss Battle（先生がボス・全員で倒す）**、Lava Rising・One Way Out など協力型 | **先生を相手にしたクラス全員の協力戦** | — |
| **Kahoot!** | 93本の研究レビューで、成績・教室の雰囲気・不安の軽減にプラス（Wang & Tahir 2020） | ライブ性（全員が同時に答える） | **何度も使うと飽きる（新しさの効果）**。競争が中身より目立つと、問題でなく勝ち負けを見る |
| **Prodigy**（算数RPG） | バトル・ペット・アバター。9万校以上が宿題に | 学校に入り込む RPG の形 | **有料会員の押し売り**（19分で広告16回・問題4問と指摘）、会員限定の宝箱・ペット・エリア。子どもの不公平感と保護者の不信 |
| **Duolingo** | 連続日数・リーグ・**フレンドストリーク**（DAU の3分の1が使用）、半数以上が友だちをフォロー | **友だちと一緒に続ける**しくみ | 日の連続を煽ること（前のメモで扱った） |
| **Minecraft Education** | GIGA スクールで全教科に広がる。立命館小の「京都を英語で案内」 | **作ったものを英語で説明する**課題 | 教室が自分で授業を組み立てる前提（民間の英語教室には重い） |
| **Roblox Learning Hub**（2025年7月） | 学びの体験を集めた入口（Words of Power など英語もある） | **U-Speak Roblox を載せる**価値あり（発見の入口） | — |
| **マグナとふしぎの少女** | 70時間のアニメ、3,000語、**声に出すとRPGの技になる** | 物語で引っぱる | 大がかりなアニメ制作（費用） |
| **Lingokids**（月2,500円） | 2〜8歳、歌・ゲーム・動画3,000以上 | 低年齢の入口 | — |
| **ClassDojo・Seesaw** | 子どもの作品が保護者に届き、保護者が反応できる | **保護者が「見る」だけでなく「応える」** | 連絡アプリが増えすぎて保護者が疲れる（教員平均3.2個・保護者2.8個、9割が1つにまとめたい） |
| **Roblox 英会話（B2C）** | 月6,900〜10,780円、人の講師＋ゲーム | — | 保護者を教室から直接取りに来る（前のメモ） |

## 3. 学習科学：何が効いて、何が逆効果か

| 分かっていること | 数字 | 設計への意味 |
|---|---|---|
| ゲーミフィケーションは全体として効く | g ≈ 0.82（教育全般）、ただし**小学生では g ≈ 0.39** と小さめ | 「ゲームにすれば伸びる」ではない。小学生には**中身の設計**が効く |
| デジタルゲームでの第二言語の語彙 | d ≈ 0.99（ゲームでない活動と比べて） | 語彙はゲームと相性がいい |
| **間隔練習・想起練習** | 250以上の研究で一貫。子どもの語彙でも1週間後まで差 | **まちがいを日をあけて戻す**（1章の足りないもの②） |
| **多読（やさしい本をたくさん）** | 語彙に大きな効果（d ≈ 1.3、古い研究）。新しいメタ分析では d ≈ 0.41（小〜中） | 「えほんの図書館」は効くが、魔法ではない |
| **協力 ＞ 競争** | 協力学習は競争・個別より効果が高い（164研究）。ゲーミフィケーションでも「競争＋協力」は「競争だけ」より行動面の成果が高い（Sailer & Homner 2020） | **クラス協力レイド・みんなのメーター** |
| **順位表は下位の子に害** | 下位の子の恥ずかしさ・不安・離脱。匿名化や段階表示で和らぐ | **週間トップ10は見直す**（5章） |
| **物のごほうびは内発的動機を下げる**（特に子ども） | 128研究のメタ分析（Deci・Koestner・Ryan）。**ことばのほめ・情報としてのフィードバックは下げない** | コインで釣らない。**実績は「予告なし・あとから」**、ことばで返す |
| **子どもの非母語の音声認識はまだ弱い** | 子ども向けに調整したモデルでも単語誤り率30〜60%。教室の雑音で悪化 | **発音で厳しく×にしない**。言えたかの目安にとどめ、「やさしい」判定を残す |
| **情報の食い違いを埋める課題**（インフォメーションギャップ） | 子ども向けの協働課題の定番。協力が必要なゲームで学習成果・協力の質が上がった研究 | **2人で解く伝えあいパズル** |

## 4. 日本の事情

- **小学校で600〜700語、中学で1,600〜1,800語**（合わせて2,200〜2,500語）。2021年の改訂で中学英語は
  難しくなり、**小学校の「楽しい英語」から中学の「覚える英語」への段差（中1ギャップ）**が大きい。
  → **学校の単語モード**（小学校・中1の語彙に合わせた出題）は、保護者の「何につながるの？」に直接答える。
- **フォニックス**は子ども英語教室で広く取り入れられている。
- **保護者の連絡は LINE。** 学校から LINE で連絡できたら「魅力的」が保護者71%、導入校では80〜95%が利用。
  塾・習い事でも「メールは見ないので LINE で」が増えている。
- **GIGA スクールの端末**（Chromebook・iPad）が子ども1人1台。Web 版はそのまま動く。
- **フランチャイズの本部**：ECC ジュニア約14,000教室、ベネッセ BE studio 約1,700教室。

## 5. Web 版に入れるべきゲーム要素（優先順）

**約束（全部に共通）**：採点・コイン・記録はサーバーが決める（今と同じ）。AI を使わない
（固定費のまま）。順位は作らない（協力で置きかえる）。

### S1. クラス協力レイド（先生が始める、授業の15分）

- 先生コンソールの「⚔ クラスで たたかう」で開始。**クラス全員の画面に同じボス**が出る。
- 各自が自分の端末で問題に答え、**正解がボスへのダメージ**になる（まちがえても減らない。全員で1本のHPを削る）。
- 問題は**先生が選ぶ**：英検の級・今日のおつかいの単語・（S3 のあとは）教室の単語リスト。
- 終わったら「クラスで◯問正解・いちばん多くダメージを出した問題」を出す。**個人の順位は出さない**。
- 遊び方は Blooket のように**あとから増やせる**形にしておく（中身＝問題、遊び方＝モード）。
  次のモード候補：「おばけ島の封印」（夜のおばけと同じ見た目）、「島を守る」（タワーディフェンス）。
- 載せ方：アリーナのバトルの採点（`battle.js`）・集合（`gather`）・英検の問題（`eiken.js`）がもうある。
- 大きさ：**中**。

### S2. まちがいノート＋間隔反復（サーバー側）

- どの島でも**まちがえた問題**を、その子の「まちがいノート」に入れる。
- 1日後・3日後・7日後・14日後に**今日の5ふんに混ぜて**戻す（正解したら次の間隔へ、まちがえたら最初から）。
- マイページに「まちがいノート：あと◯問」。保護者レポートに「今月、まちがいから覚えなおした問題 ◯問」。
- オフラインRPGにある間隔反復（`adventure-data.js`）の考え方を、サーバーの採点と記録に移す。
- 大きさ：**中**。

### S3. 教室の単語リストを取り込む

- 先生が CSV（`英語,日本語` だけでよい）か、教科書の単元名を選ぶ。
- 取り込んだ単語は**ことばの学校・今日の5ふん・クラス協力レイド・つり**に流れる。
- 形式は Roblox 版の単語 CSV（`eiken-vocab-csv`）と合わせ、**同じファイルを両方に入れられる**ようにする。
- **ハイブリッドの価値が一番わかりやすい機能**（Roblox でも Web でも、教室の単語で遊べる）。
- 大きさ：**中**（保存の列を1つ足し、出題の元を切りかえる）。

### S4. 2人で解く伝えあいパズル

- 2人1組。**Aさんだけが絵（例：部屋のどこに猫がいるか）を見ていて**、Bさんは地図の上で選ぶ。
  Aさんは**定型文（`The cat is under the table.` を組み立てる）か通話**で伝える。
- 役を交代して2回。**2人とも正解で初めてクリア**。
- 島のどこかの「ふたごの家」に2人で入ると始まる（今の「建物に入る＝その活動」と同じ形）。
- 先生は「今日はこのペアで」を名簿から組める。
- 大きさ：**中〜大**（定型文の組み立てはおつかい・英検の書くの部品を使える）。

### S5. みんなのメーター＋月替わりイベント

- **クラスで今月◯問**のメーター（例：1,000問で「おばけ島の封印」がとける）。**個人の順位のかわり**。
- 毎月1つ、**期間限定のイベント**（10月ハロウィン、12月冬の市、3月卒業…）。
  限定の服・家具は**英語で答えて**手に入る（お金では買えない）。
- 保護者レポートにも「今月のイベント：クラスで達成」。**毎月、戻ってくる理由**になる。
- 大きさ：**小〜中**（イベントはデータで足せる形にする）。

### A6. えほんの図書館（多読）

- レベル別の短いおはなし（1冊3〜8ページ）を、読み上げつきで。読んだら2問だけ。
- 「読んだ本の数」をマイページと保護者レポートに。
- 中身は書き起こしが必要（外部の本は著作権の確認が要る）。**費用の中心は中身**。
- 大きさ：**中**（仕組み）＋**継続的な中身づくり**。

### A7. フォニックスの島

- 音を聞いて文字を選ぶ・文字から音を選ぶ（**聞くと選ぶ中心**。音声認識の弱さに頼らない）。
- 低学年の入口。フォニックスを取り入れている教室への説明がしやすい。
- 大きさ：**中**。

### A8. 学校の単語モード

- 小学校の600〜700語、中1で出る語を目安に出題。保護者レポートに「中1の教科書で出る語のうち◯語」。
- 教科書の本文や音声は使わない（著作権）。**語のリストと自分たちの例文**で作る。
- 大きさ：**小**（S3 の仕組みができれば、リストを1つ足すだけ）。

### A9. 実績（あとから・予告なし）

- 「はじめて面接の間を最後までやった」「まちがいノートを10問覚えなおした」など、**学びの行動**に対して、
  **終わったあとで**ことばで知らせる。コインは付けない（物のごほうびは動機を下げる）。
- 大きさ：**小**。

### B10. 保護者が「応える」

- 保護者レポートに「👏 よくがんばったね」を1押しで返せる。子どもの画面に「おうちの人から 👏」。
- ClassDojo・Seesaw の形。**保護者が見るだけでなく応えると、子どもにも届く**。
- 大きさ：**小**（ただし保護者の連絡口を増やしすぎない：LINE とまとめて考える）。

### 変える・やめるもの

| 何を | どうする | なぜ |
|---|---|---|
| **週間XPランキング（トップ10）** | 「クラスで今週◯XP」＋「自分の先週との差」に置きかえる。残すなら**トップ3＋自分だけ** | 10人前後の教室では、トップ10に入らない1〜2人が**名指しと同じ**になる。順位表は下位の子の不安・離脱を招く研究が多い。教室の「順位を作らない」方針とも合わない |
| **会員限定・有料の宝箱** | 入れない | Prodigy が保護者団体から苦情。子どもの不公平感と教室への不信 |
| **子ども同士のトレード** | 入れない（プレゼントも、入れるなら先生の許可制） | 交換のもめごと・だまし合いは、教室が責任を持てない |
| **発音の厳しい機械採点** | 今の「やさしい」判定と「おしい」を残す | 子どもの非母語の音声認識は誤りが多い（30〜60%） |
| **コインを増やして釣る** | 増やさない。**ことばのほめ**を増やす | 物のごほうびは子どもの内発的動機を下げる |

## 6. 別プラットフォーム：どこに広げるか

| 先 | やる？ | 理由 |
|---|---|---|
| **LINE（保護者へ）** | **やる（いちばん先）** | 保護者の7割が学校との連絡を LINE で「魅力的」と答え、導入校では8〜9割が使う。月初に「◯◯さんの9月のまとめができました」とレポートのリンクを届けるだけで、**レポートが実際に読まれる**。教室の LINE 公式アカウントから送る形なら、教室の連絡口は増えない |
| **ホーム画面に置ける Web アプリ（PWA）** | **やる** | iPad で「ホーム画面に追加」すると、アプリのように全画面で開く。通知は iOS 16.4 以降、ホーム画面に置いた場合だけ届く（Safari のタブからは届かない）。費用はほぼゼロ |
| **フランチャイズ本部** | **提案する** | ECC ジュニア約14,000教室・BE studio 約1,700教室。**本部が欲しいのは教室ごとの継続率**（「教室のようす」）。1本の契約で何百教室にもなる |
| **Roblox Learning Hub** | **申請を調べる** | 2025年7月に始まった学びの入口。U-Speak Roblox が載れば、家庭からの発見が増える（載る条件は要確認） |
| Google Classroom アドオン | 今はやらない | 学校側に上位ライセンスが要り、相手は公立校。民間の英語教室には関係が薄い |
| Minecraft Education | やらない | 学校向け。作り直しになる。Roblox と Web で足りている |
| ネイティブアプリ（App Store） | 今はやらない | 子ども向けカテゴリの審査・費用。PWA で足りる |

## 7. 順番（3か月の目安）

| 月 | やること | 教室にとって何が変わるか |
