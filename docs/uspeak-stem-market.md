# U-Speak STEM の市場規模（2026-10-01）

対象は STEM 全般（宇宙・物理・化学・生物・地学・工学・データ／4〜15歳／英語が主・日本語に切り替え）。
設計は `docs/uspeak-stem-design.md` を参照。

**数字の読みかた**

- 調査会社の推計は、会社によって **最大4.5倍** も違う（K-12 STEM の例）。なので**参考にとどめ**、
  **子どもの人数（公式統計）× こちらの値段** で積み上げた試算を主にした。
- 計算はすべて下に書いてあり、検算できる。為替は 1ドル＝150円。
- 【仮定】は、こちらで置いた数字。【未検証】は、一次資料をまだ確かめていない数字。

**いちばん大きい池は、英語圏の学校とホームスクール**（TAM の約3/4）。

**TAM に入れていない伸びしろ**

- **大人・高校生**：宇宙・化学の一般向け。

## 3. SOM（5年目の売上、3つのシナリオ）

| | 控えめ | 基本 | 強気 |
|---|---|---|---|
| 日本の英語教室・塾（年4,800円＝月400円） | 5,000人 → 0.24億円 | 20,000人 → 0.96億円 | 50,000人 → 2.4億円 |
| 日本の公立（年1,800円） | 0 | 2自治体・5万人 → 0.9億円 | 10自治体・20万人 → 3.6億円 |
| 家庭（英語圏中心、年12,000円＝80ドル） | 2,000人 → 0.24億円 | 10,000人 → 1.2億円 | 40,000人 → 4.8億円 |
| インターナショナルスクール（1校500人 × 年2,250円） | 5校 → 0.06億円 | 30校 → 0.34億円 | 100校 → 1.1億円 |
| **合計** | **約0.5億円** | **約3.4億円** | **約12億円** |

**基本シナリオの3.4億円は SAM の約0.5〜1%。** 英語版の売上には、この数字を上乗せする。

**SOM を左右するのは、次の3つ。**

1. **家庭向けの継続率**：英語圏の家庭は、いちばん単価が高い（年80ドル）。
2. **公立の1自治体目**：1つ入ると、同じ作りの近くの自治体に横に広がる。2028年度に始まる次期学習指導要領の先行実施がきっかけになる。
3. **英語教室の網**：ツリーベルから始めて、営業代行の網で何教室に入れるか。

## 4. 化学の仮想実験室が求められている根拠

| 調査 | 数字 | 出典 |
|---|---|---|
| 小学校の担任で、理科の指導が「苦手」 | 約5割 | JST 小学校理科教育実態調査（2010年度）[59] |
| 分野別の苦手意識 | 物理 約67%、**化学 約56%**、生物 約47% | 同上 |
| 中学校で実験の妨げになっていること | **準備・片付けの時間が無い 66%**、設備・備品が足りない 54%、実験室が足りない 34% | JST 中学校理科教育実態調査（2012年度）[60] |
| 海外の使われかた | 仮想実験は、本物の実験の前の予習（プレラボ）として広く使われている | ACS J. Chem. Educ. [61] |
| PhET の利用規模 | 年2.5億回以上起動、約5,000万人（2024） | [49] |

→ **先生が苦手で、準備に時間がかかり、設備が足りない。** 化学室は、この3つを同時に解く。
ただし調査が古い（2010年度・2012年度）ので、全国学力調査（2025年度）の理科の質問紙で新しい数字を確かめること【未検証】[62]。

## 5. 注意

- **子ども英会話の市場は縮んでいる** [19]。英語教室向けは「STEM で付加価値をつけて単価を上げる」提案として出す。
- 日本の公立の予算：ICT 整備の地方財政措置は1年1,464億円 [55] だが、端末と回線の分を含む。**デジタル教材に回る分は公表されていない**【未検証】。
- 標本調査の受講生数（34.1万・125.6万）は全数ではない。実際の SAM はこれより大きい。
- インターナショナルスクールの在籍者は 560万ではなく **740万（2025）→ 770万（2026）**（前回の調査の数字を訂正）。
