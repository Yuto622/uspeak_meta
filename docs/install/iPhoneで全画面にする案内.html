iPhone で U-Speak を全画面で遊ぶ

保護者・教室の方向け　｜　アプリのダウンロードは不要です
iPhone のブラウザ（Safari・Chrome）では、画面の上下にブラウザのバーが残ります。これは Apple の仕様で、ページの側からは消せません。 ホーム画面に U-Speak を追加すると、バーのない全画面で開けるようになります。追加は最初の1回だけで、その後はアイコンを押すだけです。

お子さまの画面に出る案内

iPhone のブラウザで遊んでいると、島に入って少ししてから1回だけ、この案内が出ます。「わかった」を押すと閉じて、二度と出ません。

iPad・Android・パソコン、すでにホーム画面のアイコンから開いているときは出ません。

ホーム画面に追加する（1分）

Chrome で 開いた とき → この ページの 手順（アドレスバーの 右に 共有ボタン）
Safari・LINE から 開いた とき → 2 ページ目の 手順（画面の 下の ••• から）

Chrome の 場合。実際の iPhone の画面です（連絡先やほかのアプリにはモザイクをかけています）。

1共有ボタン

アドレスバーの右（Safari は画面の下のことも）の 共有ボタン（四角から上向きの矢印）を押します。見当たらないときは ••• の中の 共有。

2ホーム画面に追加

メニューを上へ引き出して（下へスクロールして） ホーム画面に追加 を押します。

3追加

名前が「U-Speak」になっていることを確かめて、右上の 追加。「Webアプリとして開く」が出たらオンのままにします。

4アイコンから開く

ホーム画面に緑の u. が出ます。次からはこのアイコンから開いてください。

Safari で 開いた とき・LINE から 開いた とき（1分）

LINE で 届いた リンクを 押すと、LINE の 中の ブラウザで 開きます。そこからは ホーム画面に 追加できないので、まず Safari で 開きなおします（①）。はじめから Safari で 開いている ときは ② から。

実際の iPhone（iOS 26・Safari）の 画面です（連絡先と ほかの アプリには モザイクを かけています）。

1ブラウザで開く

LINE から 開いた ときだけ。右下の ⋮ を 押して ブラウザで開く。Safari に きりかわります。

2••• → 共有

Safari の 画面の 下の ••• を 押して、いちばん 上の 共有。

3ホーム画面に追加

出てきた メニューを 上へ 引きあげて（下へ スクロールして） ホーム画面に追加。

4追加

「Webアプリとして開く」が オン（緑）なのを 確かめて、右上の 追加。

5アイコンから開く

ホーム画面に 緑の u. が 出ます。次からは この アイコンから 開いてください。

よくある質問

アイコンから開いたら、名前を聞かれたiPhone はアイコンと Safari で保存場所が分かれているため、最初の1回だけ名前とクラスのあいことばを入れ直してください。学習の記録・コインはサーバーにあるので消えません。
LINE で 開いたら 追加が 出ないLINE の 中の ブラウザからは 追加できません。右下の ⋮ → ブラウザで開く で Safari に してから、2 ページ目の 手順で 追加してください。
アプリのダウンロードは必要？いりません。容量もほとんど使いません。新しい版は開くたびに自動で入ります。
案内を消してしまったこのページの手順で、いつでも追加できます。
アイコンを消したいアイコンを長押し → 削除。学習の記録は消えません。
Android・iPad は？Android のスマホは、最初に画面にさわったときに自動で全画面になります。iPad はそのまま遊べます（ホーム画面に追加すると、同じように全画面になります）。
話す練習のマイクアイコンから開いて初めて話す練習をするとき「マイクの使用を許可しますか？」と出たら 許可 を押してください。
