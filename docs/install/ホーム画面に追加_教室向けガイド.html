U-Speak をホーム画面に追加する

教室の先生・スタッフ向け　｜　アプリのダウンロードは不要です
U-Speak はブラウザで動く教材です。ホーム画面にアイコンを置くと、アプリと同じようにワンタップ・全画面で開けます。 App Store からのダウンロードもアカウントも不要で、容量もほとんど使いません。新しい版は自動で入るので、更新作業もありません。

開くページ（教室専用のURL）

教室ごとのURLを U-Speak Lab からお送りしています。必ずそのURLを開いてからホーム画面に追加してください。追加したアイコンは、そのクラスに入った状態で開きます。

教室のURL：https://uspeak-multiplayer.fly.dev/?class=

左のQRは共通の入口です（クラス名を自分で入力する場合）。

台数で、いちばん早い方法を選んでください

教室で管理しているiPad・Chromebookが多いいちばん早い

端末の管理画面から全台に一度に配るのがいちばん確実です。子どもが操作する必要はありません。手順は2ページ目の「C」をご覧ください。

数台だけ・ご家庭の端末1台1分

端末ごとに下の手順で追加します。保護者の方にお願いする場合も、このページをそのまま渡してください。

A　iPad・iPhone

  1. Safari で教室のURLを開きます。（iPadOS / iOS 16.4 以降なら Chrome・Edge でも同じ手順でできます）
  2. 画面上（iPhone は下）の 共有ボタン をタップします。
  3. メニューを下へスクロールして ホーム画面に追加 をタップします。
  4. 名前が「U-Speak」になっていることを確認して、右上の 追加 をタップします。
  5. ホーム画面に緑の u. のアイコンが出ます。次からはこのアイコンから開いてください。

「ホーム画面に追加」が出ないときは、プライベートブラウズになっていないか、LINE などのアプリ内ブラウザで開いていないかを確認し、Safari で開き直してください。

B　Android・パソコン（Chrome / Edge）

Android（Chrome）

  1. Chrome で教室のURLを開きます。
  2. 右上の ⋮ → ホーム画面に追加（または アプリをインストール）。
  3. インストール をタップします。

Windows・Mac・Chromebook

  1. Chrome か Edge で教室のURLを開きます。
  2. アドレスバー右端の インストール アイコン（画面に矢印）を押します。
    見つからないときは ⋮ → 「キャスト、保存、共有」→「ページをアプリとしてインストール」
  3. デスクトップやアプリ一覧から開けるようになります。

C　管理している端末に一斉に配る（管理者向け）

iPad（Apple School Manager ＋ MDM）

  1. MDM（Jamf・Intune・LanScope など）で、iPad 向けの 「Webクリップ」 を新しく作ります。
  2. ラベル：U-Speak　URL：教室のURL
  3. アイコン：下のURLの画像を登録します。
    https://uspeak-multiplayer.fly.dev/assets/app/apple-touch-icon.png
  4. フルスクリーン をオンにして、対象の iPad に配信します。

項目の名前は MDM の製品によって少しちがいます。学校の端末の場合は、教育委員会や ICT 支援員の方にこのページをお渡しください。

Chromebook（Google 管理コンソール）

  1. 管理コンソール → デバイス → Chrome → アプリと拡張機能 → ユーザーとブラウザ。
  2. 右下の ＋ から URL で追加（Add by URL）を選び、教室のURL を入れます。
  3. インストールのポリシーを 強制インストール にします。

配信先の組織部門をまちがえないようご注意ください。

はじめて開いたとき

  1. 名前とクラスのあいことばを1回だけ入れます。 iPad・iPhone はホーム画面のアイコンと Safari で保存場所が分かれているため、Safari で入れていても、もう一度入力が必要です。
  2. 学習の記録・コインは消えません。 記録はサーバーに保存されているので、同じ名前・同じクラスで入れば続きから遊べます。
  3. 話す練習を初めて使うときに「マイクの使用を許可しますか？」と出たら 許可 を押してください。

こまったとき

こんなときこうしてください
マイクが使えないiPad：設定 → Safari → マイク を「確認」か「許可」に。Android・パソコン：アドレスバー左の鍵マーク → マイク → 許可。
共用の iPad で次の子に代わる画面上のバーの ⏏（ログアウト） を押すと、名前とクラスが消えて次の子が入れます。
アイコンを消したいアイコンを長押し → 削除。学習の記録はサーバーにあるので消えません。
新しい版にしたい作業は不要です。開くたびに最新の版が読み込まれます。
別のクラスで使う端末クラスごとにそのURLを開いて追加すると、アイコンがクラスの数だけ並びます（どれも「U-Speak」なので、追加するときに名前を「U-Speak 月曜A」などに変えると分かりやすくなります）。
画面が小さい・見づらいiPad・iPhone は横向きでお使いください。

導入日のチェックリスト

  • 教室のURLを U-Speak Lab から受け取った
  • 先生の端末でアイコンを追加し、開けることを確認した
  • 生徒の端末に追加した（台数が多いときは C の一斉配信）
  • 1台で名前とあいことばを入れて、クラスに入れることを確認した
  • 話す練習でマイクの許可を出した
  • 保護者の方に、ご家庭で使う場合の手順（A・B）を渡した

ご不明な点は、U-Speak Lab の担当までお気軽にご連絡ください。
