## 起動

ZIPを展開し、このREADMEのあるフォルダーで実行します。Python 3が必要です。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Windowsでpythonが使えなければ `py -3` に置き換えます。
http://127.0.0.1:8000 をWebGL対応ブラウザーで開いてください。終了はCtrl+C。
HTMLのダブルクリックではなくHTTPで起動します。
ビルド・npm installは不要。`dist/` が手書きの実ソースです。
Three.js r160はローカル同梱されています。

## 保存

ブラウザーのlocalStorageを使用。サーバーDB・アカウント同期・マルチプレイはありません。
公開URLとローカルURLではセーブが別になります。このZIPにプレイヤーのセーブは含みません。
RPGバックアップ機能の範囲と、釣り・アバターの別保存領域を混同しないでください。

## テスト

Node.js 24で確認済みです。

```sh
node tests/regression.mjs
```

実際のThree.jsオブジェクトと模擬DOM/rendererで、屋内・売買・移動・宝箱・鍵・保存を確認します。
`THREE.WebGLRenderer: canvas.getContext is not a function` は模擬環境で
プレビューのフォールバックを通すための表示です。終了コード0とPASSを確認してください。
GPU描画やブラウザー・スマホ操作の実機QAを代替するテストではありません。
